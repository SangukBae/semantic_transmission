## 기본 예측 압축 BSU의 전송량·품질 평가

2026-10-16 비교는 동일 Kinetics 개발 영상 14편·3,333프레임·576×320·24fps·10dB의 **전달 MP4**를 사용한다. PSNR·SSIM·LPIPS-VGG·CLIP·DISTS는 영상 내 프레임 평균을 먼저 계산한 뒤 영상별 동일 비중으로 집계한다. Top-1/5는 동일 TimeSformer 설정의 영상별 정답 건수다. [모델별 결과](RESULTS.md#bsu-predictive-default)

전송량은 **복소 채널 사용량**이다. 예측 경로의 DCVC 비트스트림·캡션·구간·시점·모델/경로 식별자·헤더·CRC와 LDPC(6144,9216) 패딩/패리티를 포함한 16QAM 심벌에, 생성 경로의 실제 NTSCC 심벌과 디지털 패킷을 더한다. 수신 RIFE 보간 자체의 추가 전송은 0이다. 송신부에서 시험만 하고 선택하지 않은 후보는 전송 비용에서 제외하되 계산 시간은 발생한다. 사전 설치한 공통 모델과 물리 링크 추가 헤더는 양쪽 모두 제외한다. 저장 MP4·complex64 바이트를 무선 비트 수로 바꾸지 않는다.

실제 디지털 패킷은 시드 42·1042·2042에서 모두 복호 일치를 검사했으며 비용은 한 번의 전송으로 센다. 세 시드를 독립 영상 42편으로 늘리거나, 모든 생성 잡음을 세 번 시험했다고 표시하지 않는다. 기본 경로 선택은 키 수와 실제 전송 비용만 읽고 화질·라벨은 읽지 않는다. 후속 적응형 탐색은 송신 원본으로 품질을 검사하지만 행동 라벨은 선택 후 평가에만 사용한다.

영상별 공학적 품질 유지 기준은 PSNR 손실 ≤0.10dB, SSIM 손실 ≤0.005, CLIP 손실 ≤0.002, LPIPS·DISTS 증가 ≤각 **1% 상대값**, 광류·움직임 변화 오차 증가 ≤각 2%, 거짓 정지 비율 증가 ≤0.005, 고정 키 경계 오차 증가 ≤5%다. 전체·고정 비키 화질을 모두 검사하고 교체 후보에는 실제 총전송 감소도 요구한다. 기본 모델 채택은 이전 BSU 기준, 후속 간격/QP 실험은 **새 기본 BSU 기준**이다. 정지 비율은 공간 셀 기반 진단으로 정지 프레임의 백분율이 아니다.

허용 기준 통과는 바이트 동일 출력이나 통계적 비열등성·독립 의미 보존 입증이 아니다. 기존 영상 재사용과 새 복원 건수를 따로 기록한다. [원 검증 요약](validation/2026-10-16-bsu-predictive-final.json) · [후속 결과](validation/2026-10-16-bsu-adaptive-rate.json)

## WebVid 전체 영상 배치

[`bsu_webvid.py`](../src/semantic_transmission/bsu_webvid.py)는 [LGVSC 논문 III-C](https://arxiv.org/html/2606.12899v2#S3.SS3)의 프레임 평균 평가에 맞춰, 기존 공식 구현 기준 PSNR·회색조 SSIM·LPIPS-VGG·CLIP ViT-B/32 cosine01·DISTS를 모든 프레임에서 계산한다. 생성 PNG와 최종 전달 MP4를 별도로 저장하며 기본 비교표는 전달 MP4다. 길이가 다른 영상의 **영상별 평균에 동일 가중치**를 준 값과 **전체 프레임 가중 평균**을 함께 보고한다. 논문은 프레임 평균을 명시하지만 영상 간 집계 가중치는 확정하지 않았으므로 둘 중 하나를 논문과 정확히 동일하다고 표시하지 않는다.

CBR 분모는 `3 × 정규화 높이 × 너비 × 전체 프레임 수`, 분자는 실제 NTSCC 복소 심벌 + 기본 메타데이터 LDPC/QAM 심벌 + 추가 궤적 LDPC/QAM 심벌이다. 별도 궤적 패킷의 헤더·패딩·패리티를 포함하며, complex64 파일의 저장 바이트를 무선 비트 수나 BPP로 바꾸지 않는다. 전체 심벌/전체 원본 스칼라 비율과 영상별 CBR 평균을 함께 저장한다. 논문 Table I의 SKEM+DSA CBR은 6/8dB에서 `0.00064`, 10dB에서 `0.00065`이며 **다른 조건의 참고값**이다. NTSCC 가중치·부가정보 회계의 등가성은 미확인이다.

현재 준비 53편은 공개 manifest 55편의 부분집합이다. 미완료·실패를 점수 0으로 채우지 않고 집계에서 제외하면서 분모와 누락 목록을 표시한다. `COMPLETE`는 선택한 영상/SNR 조건의 복원·정량 완료이며, 55편 완전 재현·독립 의미 검수 완료를 뜻하지 않는다. 보정 출력에는 광류·움직임 변화·거짓 정지 등의 진단도 기록한다. [실행·출력](RUN_GUIDE.md#bsu-webvid-benchmark)

디지털 메타데이터는 6/8dB에서 LDPC(6144,9216)·QPSK, 10dB에서 같은 LDPC·16-QAM을 사용한다. 동일 크기 패킷에서 QPSK의 복소 심벌 수는 두 배다. 시각 NTSCC의 SNR과 잡음 정책은 바꾸지 않으며, 표의 CBR은 이 로컬 링크 정책을 포함한다.

## 기존 화질 지표

- **PSNR:** 원본과 픽셀 값이 얼마나 비슷한지; 높을수록 좋음.
- **SSIM:** 영상의 구조가 얼마나 비슷한지; 높을수록 좋음.
- **LPIPS:** 눈에 보이는 차이를 특징으로 측정; 낮을수록 좋음.

화질 점수만으로 객체의 추가·누락·왜곡 감소를 판단할 수 없어 새 의미 지표를 개발 중.

## BSU 복원 대조의 평가 경계와 전송 예산

10월 10일 움직임 실험은 **MP4 저장 전 PNG**를 평가했다. 역사적 LGVSC·고정 22키와의 참고 비교는 공통 원본 **0~380번 381장**, 새 후보의 판정은 항구 전체 384장과 각 짧은 창 49장이다. 전체·비키 화질을 구분하며, CNN의 추가 기여는 같은 수신 움직임을 사용하는 정렬 전용 조건과 비교한다. 캡션만 교체한 효과와 움직임 효과를 합산하지 않는다.

| 항목 | 이번 실험의 계산·해석 |
|---|---|
| 화질 | 576×320 RGB의 PSNR·SSIM·LPIPS-VGG·DISTS·CLIP. PSNR·SSIM·CLIP은 높을수록, LPIPS·DISTS는 낮을수록 좋지만 의미 오류율을 대신하지 않음 |
| 원본 대비 광류 오차 | 288×160 bilinear 축소·회색조에서 인접 프레임의 Farnebäck 광류 계산. 원본·복원 광류 벡터 차이의 L2 크기를 공간·전환별 평균; 이 축소 해상도의 픽셀/전환 단위 |
| MAD 95백분위 | 같은 회색조 0~255 픽셀에서 각 인접 프레임의 평균 절대 차이를 구한 뒤 전환들의 95백분위. 큰 화면 변화 진단이며 낮다는 사실만으로 원본 움직임을 잘 복원했다고 판정하지 않음 |
| 조건 고정 | 같은 원본·수신 키·모델·시간 조건·실제 VAE/초기 latent/RFLOW 난수를 확인. 캡션 대조에서만 문장을, 움직임 대조에서만 해당 조건을 변경 |

10월 9일 3종 비교는 전달 MP4와 `INTER_AREA` 시간 지표 축소를 사용했다. PNG·bilinear를 사용하는 이번 수치와 직접 혼합하지 않는다. 역사적 LGVSC와 고정 22키는 키 위치·구간·실제 잡음이 달라 참고 비교이며 단일 모듈의 인과 대조가 아니다. 계산 구현은 [시간 지표](../src/semantic_transmission/receiver_alignment_evaluation.py), [후보 평가](../src/semantic_transmission/bsu_motion_evaluation.py), [공통 381장 재집계](../src/semantic_transmission/bsu_motion_context_evaluation.py)에 있다.

이번 파일럿의 사전 정량 기준은 기존 BSU 대비 **PSNR +0.3dB 이상, LPIPS 증가 0.01 이하, 광류 오차 1.05배 이하, MAD 95백분위 1.10배 이하**를 각 장면에서 모두 만족하는 것이다. 보행·회전 통과, 항구·저동작 실패로 정량 전체 기준 미달이다. 이 허용치는 보편적인 품질 기준이나 통계적 비열등성 검정이 아니다. 13개 원본 시점의 비독립·비맹검 AI 검토에서 정량 통과 장면에도 겹침·번짐이 남아, 독립 의미 검수는 미완료다.

**후속 후보의 예산 비교:** 실제 키·캡션·보조 정보·직렬화와 오류 정정 비용을 합산한다. 10월 12일 시간축 원인 대조까지는 항구 LGVSC의 **92,475 복소 채널 사용량 이하**를 사용했다. 이후 사용자가 품질 이득에 대한 소폭 증가를 허용해 궤적 실험의 탐색 상한을 **1.05배, 97,098 이하**로 정했다(+5%는 사용자 지정 수치가 아닌 이번 구현의 가정). 과거 예산 판정을 소급 변경하지 않는다. LGVSC가 측정되지 않은 6개 창은 각 2키 BSU의 1.05배를 한도로 삼았으며 이를 LGVSC 대비 달성으로 표시하지 않는다. 모델 사전 설치·물리 링크 헤더 비용은 기존처럼 제외한다. 논문의 BPP를 NTSCC/LDPC 혼합 채널 사용량과 바로 비교하지 않는다. 기존 메타데이터 여유 582바이트는 10월 10일 후보의 기록이며 새 보조 정보에는 실제 직렬화·FEC 블록 증가를 계산해야 한다.

후속 수신부만의 효과는 동일 수신 입력·잡음 대조로, 시스템 전체 효과는 같은 총전송 예산으로 분리한다. 현재 원본 재현력 목표의 참고값은 공통 381 PNG에서 고정 22키의 PSNR 20.969dB·LPIPS 0.27832다. 이 목표 달성과 시간 품질·독립 의미 오류 개선은 각각 검증한다. [실험 결과](RESULTS.md#bsu-motion-pilot) · [자료 분할](DATA.md#bsu-motion-data)

**개발 채택 원칙 — 2026-10-12 사용자 피드백 반영:** 모든 지표의 동시 개선이나 고정 22키 목표 달성을 중간 개선안의 필수 채택 조건으로 삼지 않는다. 전송 예산 안에서 원본 재현력·시간 안정성의 개선 폭과 손실 폭, 실제 출력의 오류를 함께 판단한다. 일부 지표의 소폭 악화는 더 큰 실용적 이득을 위해 수용할 수 있으며, 개선된 지표의 개수만으로 결정하지 않는다. 대체할 기존 방식과 적용 범위를 먼저 명시하고, 개발 기준안 선택과 기본 실행 경로 변경을 구분한다. 과거 사전 기준과 측정값은 보존하고 사후 채택 재평가는 별도로 표시한다. 후속 실험은 주요 목적과 허용 가능한 손실을 실행 전에 정한다. [이번 재평가](RESULTS.md#bsu-temporal-support)

## 7원본 궤적·시간 보정의 움직임 지표

[`stutter_metrics.py`](../src/semantic_transmission/stutter_metrics.py)는 같은 전체 PNG 시간축을 288×160 그레이스케일로 바꾸고 Farneback 광류를 계산한다. 광류 오차는 원본과 출력의 벡터 차이 L2 평균이다. 8×5 셀별 평균 광류 크기를 `v[t]`, 출력 값을 `v_hat[t]`라 하면 움직임 변화 오차는 `mean(abs((v_hat[t]−v_hat[t−1])−(v[t]−v[t−1])))`다. 두 지표는 픽셀/프레임 기반이며 과거 정규화 광류 지표와 혼용하지 않는다.

- 활성 셀: 원본 속도 >0.15픽셀/프레임. 거짓 정지: 활성 셀에서 출력 속도 <원본의 25%.
- 정지 후 급이동: 연속 두 전환 모두 활성이고 첫 전환은 거짓 정지, 다음 출력 속도 >원본의 180%. 분모는 연속 활성 셀쌍이다.
- 셀 수는 공간 셀×시간 전환 검출 수다. 독립 사건·프레임·사람 평가 건수가 아니다. 저동작 영상의 작은 분모도 함께 보고한다.
- 각 영상 내 평균을 구한 뒤 7영상에 같은 가중치를 준다. 백분율은 이 평균들의 상대 변화다. 프레임·셀 수로 가중한 총합과 구별한다.

낮은 움직임 변화 오차만으로는 정지 출력을 유리하게 평가할 수 있어 원본 대비 광류·거짓 정지·급이동·화질을 함께 검사한다. 원본은 오프라인 평가에만 사용한다. 실제 수신 보정은 DIS 광류·수신 패킷을 사용하며 원본 지표로 프레임을 선택하지 않는다. 임계값은 이번 진단 정의이며 보편적인 버벅임 정답이 아니다. 모든 조건은 같은 기존 BSU 생성 출력에서 시작한다. 시간 보정 대조는 유료 궤적 패킷 비용을 함께 기록하지만 실제 `cadence` 사용은 궤적이 필요 없어 **추가 전송 0**이다. [실측·채택](RESULTS.md#bsu-trajectory-cadence)

## 과거 지표 실험의 고정 정의

ERE/STA·잔존/지연·FSO/EOI/UEP는 비교·실패 분석을 위한 연구 후보입니다. 코드가 직접 복사·해시하는 원래 정의 7개는 [검증용 원문 데이터](../configs/protocols/legacy_metric_definitions.json)에 UTF-8 원문과 SHA256으로 보존했습니다. `protocol_definitions.protocol_path`가 검증 후 로컬 `.local/protocol_definitions/`에 동일 바이트로 복원합니다. 기존 출력의 `.frozen.md` 파일명과 정의 해시는 유지합니다. 이 데이터는 새 읽기용 문서 목록이나 내부 메일 저장소가 아니라 과거 평가 입력 계약입니다.

| 정의 | 재현 역할 |
|---|---|
| ERE_STA_PROTOCOL | 사건 열·귀착 정의, 원본 제외, 관측/추출 관문 |
| ERE_STA_EXECUTION_NOTES | 사전 해석과 실행 보완 |
| ERE_STA_FORMAL_EXECUTION | 본 평가 전 조건·분할·채택 기준 |
| EVENT_DURATION_STA_PROTOCOL | 사건 지속량·반영 지연·STA 정상/보류 대조 |
| FSO_UEP_PROTOCOL | 금지 상태 점유·순서 역전·근거 부족과 측정 가능성 |
| METRIC_REVISION_PROTOCOL | 관측/정답 정렬의 개발 수정 |
| METRIC_VALIDATION_CAMPAIGN | 교차·요소·자연 영상 검증 계획과 단계 |

주요 계산은 FSO=max(0, 복원 금지상태 점유율−원본 점유율), EOI=역전 순서쌍/유효 대응쌍입니다. FSO 고정 창 H=4프레임, EOI 최소 시간차 0.375초 등 각 원래 프로토콜의 조건을 적용합니다. 측정 불가는 0점으로 채우지 않습니다. UEP의 오경보·포화와 EOI의 관측 부족 등 실패 근거는 위와 결과 문서에 남깁니다. 이 정의들이 자연 영상에서 유효한 최종 지표라는 주장은 하지 않습니다.
