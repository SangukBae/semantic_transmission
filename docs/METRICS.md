## 캡션·선택·복원을 분리한 평가

| 항목 | 계산·보고 기준 |
|---|---|
| 사실 완전 재현 | 원본으로 지지한 사실 중 속성·방향 등 사전 정답 조건을 모두 만족한 수 / 유효 사실 수 |
| 부분 재현 | 사실을 일부 언급했지만 완전 정답 조건은 충족하지 못함. 완전 재현과 별도 집계 |
| 동작·변화 재현 | 시간 순서·전후 변화 정답 부분집합의 완전 재현 수 / 유효 시간 사실 수 |
| 오류 구간 | 근거 없는 객체·행동·방향 등 하나 이상 포함한 구간 / 전체 구간. 주장 개수도 별도 보고 |
| 사건 포착 | 사전 정의한 사건 근거 조건을 선택 키가 만족하는 사건 수 / 유효 사건 수. 근거 한 장 포함과 전후 양쪽 보존을 구분 |
| 전송 비용 | 실제 전송된 시각·메타데이터 바이트, 채널 사용량. 키 개수만으로 대체하지 않음 |
| 처리 시간 | 모델 로딩, 시각 인코딩, 후보/선택, 캡션, 채널, 복원을 단계별 기록 |
| 복원 의미 오류 | 원본과 시간·객체를 대응해 Added/Missing/Distorted를 판정. PSNR/LPIPS 개선과 구분 |

정답은 출력 생성 전에 원본에서 확정하고, 같은 입력·키 예산·해상도·프롬프트·출력 예산을 고정합니다. source-level train/validation/test 분리를 유지하며 이미 분석한 영상을 다시 미사용 test로 표시하지 않습니다. 교사에게만 보이는 사실은 학생 평가 입력에서 지지되는지 따로 검사합니다.

평가자의 모델·역할·독립 문맥 여부, 조건명 익명화 여부, 사람 검수 여부를 기록합니다. 같은 모델의 다른 문맥은 독립된 사람 정답이 아닙니다. 관측 불가·불확실 항목은 사전 규칙에 따라 제외/보류하고 분모·정정 기록을 함께 공개합니다. 중첩 구간을 독립 표본처럼 취급하지 않으며 필요한 신뢰구간은 원본 단위 대응 재표집으로 계산합니다.

2026-10-07 ClipShots 비교는 12원본·24구간·83사실·25동작, 원본 단위 bootstrap 5,000회입니다. 점수 기준 통과와 통계적 비열등성 입증은 다릅니다. 모든 실험에 같은 분모·완전 정답 기준을 소급 적용하지 않습니다.

## 기존 화질 지표

- **PSNR:** 원본과 픽셀 값이 얼마나 비슷한지; 높을수록 좋음.
- **SSIM:** 영상의 구조가 얼마나 비슷한지; 높을수록 좋음.
- **LPIPS:** 눈에 보이는 차이를 특징으로 측정; 낮을수록 좋음.

화질 점수만으로 객체의 추가·누락·왜곡 감소를 판단할 수 없어 새 의미 지표를 개발 중.

## 개발 중인 의미 지표

- **FSO:** 없어야 할 객체·동작·방향이 얼마나 오래 남는지 측정.
- **UEP:** 수신 정보로 뒷받침되지 않는 객체가 얼마나 나타나는지 측정.
- **EOI:** 원본의 사건 순서가 뒤바뀌었는지 측정.
- **목표:** 세 후보 중 실제 오류를 신뢰성 있게 측정할 1~2개 선정.

## 과거 지표 실험의 고정 정의

ERE/STA·잔존/지연·FSO/EOI/UEP는 비교·실패 분석을 위한 연구 후보입니다. 코드가 직접 복사·해시하는 원래 정의 7개는 [검증용 원문 데이터](../configs/protocols/legacy_metric_definitions.json)에 UTF-8 원문과 SHA256으로 보존했습니다. `protocol_definitions.protocol_path`가 검증 후 로컬 `.local/protocol_definitions/`에 동일 바이트로 복원합니다. 기존 출력의 `.frozen.md` 파일명과 정의 해시는 유지합니다. 이 데이터는 새 읽기용 문서 목록이나 내부 메일 저장소가 아니라 과거 평가 입력 계약입니다.

| 정의 | 재현 역할 |
|---|---|
| ERE_STA_PROTOCOL | 사건 열·귀착 정의, 원본 제외, 관측/추출 관문 |
| ERE_STA_EXECUTION_NOTES | 사전 해석과 실행 보완 |
| ERE_STA_FORMAL_EXECUTION | 본 평가 전 조건·분할·채택 기준 |
| EVENT_DURATION_STA_PROTOCOL | 사건 지속량·반영 지연·STA 정상/보류 대조 |
| FSO_UEP_PROTOCOL | 금지 상태 점유·순서 역전·근거 부족과 측정 가능성 |
| METRIC_REVISION_PROTOCOL | 관측/정답 정렬의 개발 수정 |
| METRIC_VALIDATION_CAMPAIGN | 교차·요소·자연 영상 검증 계획과 단계 |

주요 계산은 FSO=max(0, 복원 금지상태 점유율−원본 점유율), EOI=역전 순서쌍/유효 대응쌍입니다. FSO 고정 창 H=4프레임, EOI 최소 시간차 0.375초 등 각 원래 프로토콜의 조건을 적용합니다. 측정 불가는 0점으로 채우지 않습니다. UEP의 오경보·포화와 EOI의 관측 부족 등 실패 근거는 위와 결과 문서에 남깁니다. 이 정의들이 자연 영상에서 유효한 최종 지표라는 주장은 하지 않습니다.
