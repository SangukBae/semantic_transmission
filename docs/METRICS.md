# 평가 지표

[E3 개발 원칙](ETRI_DEVELOPMENT_PLAN.md#metrics) · [과제 현황](README.md)

## 기존 화질 지표

- **PSNR:** 원본과 픽셀 값이 얼마나 비슷한지; 높을수록 좋음.
- **SSIM:** 영상의 구조가 얼마나 비슷한지; 높을수록 좋음.
- **LPIPS:** 눈에 보이는 차이를 특징으로 측정; 낮을수록 좋음.

화질 점수만으로 객체의 추가·누락·왜곡 감소를 판단할 수 없어 새 의미 지표를 개발 중.

## 개발 중인 의미 지표

- **FSO:** 없어야 할 객체·동작·방향이 얼마나 오래 남는지 측정.
- **UEP:** 수신 정보로 뒷받침되지 않는 객체가 얼마나 나타나는지 측정.
- **EOI:** 원본의 사건 순서가 뒤바뀌었는지 측정.
- **목표:** 세 후보 중 실제 오류를 신뢰성 있게 측정할 1~2개 선정.
