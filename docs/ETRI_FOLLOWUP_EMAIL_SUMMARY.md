# ETRI 후속 메일 핵심 요청

- 출처: 사용자가 제공한 ETRI 권해찬의 중간점검 후속 메일.
- 기준일: 2026-09-21, 사용자 지시로 연구개발 요구사항에 반영.
- 핵심: **기존 연구방향을 유지하며 할루시네이션 검출·완화에 집중.**

## 요청사항

- **실험 채널:** AWGN에서 검출·완화 평가; 채널 종류별 성능 비교는 제외.
- **비교 영상:** 동일 입력·채널의 원본 / 완화 전 / 완화 후 제공.
- **오류 표시:** 가능하면 프레임·시각·객체 영역·오류 유형 표시.
- **오류 유형:** Added(추가) · Missing(누락) · Distorted(왜곡).
- **결과 보고:** 성공, 개선되지 않은 오류, 완화 중 생긴 새 왜곡 모두 제시.
- **시험 길이:** 실제로 이어지는 60초 이상 영상으로 확장 가능성 검토.
- **시험 난도:** 장면전환이 적음 / 일반적 / 빈번함의 세 유형 구성.
- **영상 구성:** 짧은 영상 반복·단순 연결 제외; 5분은 비교 사례이며 필수 아님.

## 시간 흐름·장면전환

- 저전환 영상: 키프레임에서 멀어질 때 내용이 달라지는 현상과 깜빡임 확인.
- 고전환 영상: 장면전환 검출과 키프레임·의미 패킷 갱신 확인.
- 검출 실패: 장면전환을 놓쳤을 때 사용할 대안 확인.

## 학습·동적 정보

- 학습 자료: 모듈별로 이미지·동영상 중 무엇으로 학습했는지 설명.
- 영상 학습: 시간 흐름을 복원하는 데 동영상 학습이 필요한지 검토.
- 동작 정보: 걷기·달리기·정지 준비를 구분할 속도·행동 정보 검토.
- 중간 프레임: 구간 설명·영상 요약이 객체 관계와 장면 변화를 충분히 담는지 확인.
- 발표 맥락: 메일에는 당시 동적 정보가 부족하며 보강이 필요하다고 논의한 것으로 기록.

## 범위와 해석

- 기존 목표: E1 시간축 · E2 할루시네이션 · E3 평가 · E4 전송량 유지.
- 새 지표 1~2개: 기존 과제 목표이며 이번 메일의 추가 지시는 아님.
- 학습 확인: 이미지로만 학습했다는 확정이나 특정 재학습 기법의 도입 지시는 아님.
- 시험 원본: 외부 공개 없이 내부 성능검증용으로 사용; 다양한 플랫폼 확보를 제안.
- 상태 구분: 이 문서는 요청 요약; 완료 여부는 [과제 현황](README.md)에서 확인.
