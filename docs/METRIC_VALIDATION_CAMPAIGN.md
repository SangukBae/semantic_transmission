# FSO·EOI·UEP 후속 검증의 일괄 실행

## 실행

저장소 루트에서 아래 명령 하나로 ① 오류×외형 교차 → ② 구성 요소 비교 → ③ 자연 영상 및 실제 LGVSC 복원을 순서대로 실행한다.

```bash
bash scripts/run_metric_validation.sh
```

기본 출력은 `outputs/metric_validation_20260916_v1/`이다. 실행 전에 아래 명령으로 입력과 예상 시간을 확인할 수 있다. GPU 추론과 출력 폴더 생성은 하지 않는다.

```bash
bash scripts/run_metric_validation.sh --dry-run
bash scripts/run_metric_validation.sh --status
```

다른 규모/출력 경로는 `--config configs/my_campaign.json --output outputs/my_campaign`으로 지정한다. 설정은 [metric_validation.json](../configs/metric_validation.json)에 있다. 실행 중 다른 터미널에서 `--status`로 현재 작업을 보고, `logs/`에서 진행을 확인한다. 장시간 실행은 사용자가 관리하는 tmux 세션에서 실행할 수 있다.

## 기본 규모와 순서

| 단계 | 데이터와 실행 | 평가 |
|---|---|---|
| ① 교차 실험 | 새 합성 원본 24개 × 15개 상태/순서/추가/정상 조건 × 외형 5종 = 1,800쌍 | FSO 4성분·EOI·UEP, 기존 10개 기준선, 구성 제거 지표 |
| ② 구성 비교 | 별도 합성 원본 12개 × 추가 길이 3종 × RX 조건 5종 = 180쌍 | 동일 원본·복원에 RX만 변경. FSO·EOI는 ①의 동일 관측 결과를 재사용 |
| ③ 자연/복원 | 이전 프로토콜에서 사용하지 않은 DAVIS 8개 × 최대 75조건 = 600쌍. 그중 6개는 LGVSC 30-step·10-step 각각 복원 = 12회 | 기존 마스크+알려진 편집에 의한 정답 평가, 실제 복원의 점수·시간축·RX 근거 진단 |

원본은 관측 점수와 무관하게 seed와 기존 사용 목록으로 선정한다. 합성 원본은 이전의 세 절차적 장면 계열을 재사용하므로 미관측 계열 일반화 검증은 아니다. 외형은 identity, 밝기, 텍스처, 작은 카메라 변화, 팔레트 변화이다. 합성 텍스처는 다시 렌더링하고 자연 영상 텍스처는 색상 패턴을 덧씌운다. 모든 오류에도 같은 외형 조건을 적용한다.

자연 영상은 마스크가 존재하는 JPEG 32장을 stride=1로 취해 **8 Hz의 4초 평가 영상**으로 정의한다. 촬영 원래 FPS를 안다는 뜻은 아니다. 실제 LGVSC 입력은 576×320, 24 Hz로 각 프레임을 반복하여 만든다. 기존 10초 공식 실행과 같은 입력 길이의 벤치마크는 아니다. 두 복원 설정은 샘플링 단계 수만 비교하며 새 모델 또는 개선 모델로 가정하지 않는다.

## 검증 규칙과 해석

- 기존 FSO·EOI·UEP와 기준선 임계값은 v5 결과의 값을 그대로 사용한다. 추가 구성 제거 지표만 이전 개발 정상 600쌍의 95백분위(`higher`)에서 임계값을 정한다. 새 평가 점수로 조정하지 않는다.
- FSO는 원본 차분 제거, 움직임의 자기 기준 속도 제거, 방향의 자기 기준 방향 제거를 비교한다. EOI는 매칭된 사건의 Kendall형 역전율, 누락된 쌍을 벌점으로 넣는 변형, 시간 허용범위 안에서만 사건을 대응하는 변형을 비교한다. UEP는 source-only와 RX-only를 비교한다. 별도 문헌 최신성/신규성 검토를 대체하지 않는다.
- RX 조건은 없음, 완전 지원, 일부 지원, 체크섬 손상, 희소 전송이다. 객체 삽입 마스크와 실제 PNG 디코딩 성공 슬롯으로 정답을 만들고, 점수 추출기는 RGB와 디코딩 상태만 받는다. 실제 통신 채널 전체를 재현하는 RX 벤치마크는 아니다.
- 정답은 렌더러의 위치·가시성, 원래 DAVIS 마스크, 편집 인덱스, 삽입 마스크에서 구한다. SAM2/DINO/RAFT 점수로 정답을 만들지 않는다. 시간 창 등 평가 정의는 지표 정의와 공유한다. DAVIS 마스크는 선택된 객체만 포함한다. 그 밖의 객체 전체를 정답으로 보증하지 않는다.
- 목표 오류가 있는 경우와 없는 경우를 지표별로 나눈다. 다른 종류 오류라도 해당 지표의 정답 값이 0이면 그 지표의 음성 사례다. 정답/관측 불가를 0으로 바꾸지 않는다.
- 지표별 탐지 기준은 AUC≥0.90, 탐지율≥0.80, 오경보율≤0.10, 양성/음성 각각 관측률≥0.95이다. 각각 최소 5개 원본이 필요하다. 조건별 결과와 원본을 단위로 한 bootstrap 신뢰구간을 함께 남긴다. 조건 수가 원본 수로 계산되지 않는다. 기준선 차이는 동일하게 관측 가능한 쌍만 사용하고 표본 수를 표시한다. 이 탐색적 다중 비교는 논문 수준의 다중검정 보정을 제공하지 않는다.
- 실제 복원은 원본과 물리적 타임스탬프로 대응한다. 잘린 꼬리·추가 꼬리·대응률을 기록하고 시간 늘이기나 내용 기반 보정을 하지 않는다. RX는 저장된 키프레임을 유지하는 진단용 근사이며 caption/flow의 의미 근거를 해석하지 않는다. 따라서 UEP 진단도 키프레임 근거 범위로 제한된다.
- **실제 생성 복원의 독립 정답은 자동 생성하지 않는다.** 기본 결과는 `REQUIRES_INDEPENDENT_RECONSTRUCTION_TRUTH`이다. 자연 영상의 통제 편집 평가를 실제 생성 복원 정확도라고 표시하지 않는다. 적합한 사건이 적으면 `INSUFFICIENT_TRUTH`로 남는다.

`03_natural/independent_truth.template.json`은 복원 후 만들어진다. 실제 복원에 대해 별도로 확보한 정답을 넣으려면 정확한 source/reconstruction/alignment SHA256, 근거 파일의 절대경로와 SHA256, 정답 생성 방법을 제공해야 한다. 이 형식 검사는 근거의 독립성 자체를 인증하지 않는다. UEP 정답은 `received_keyframes_only` 근거 범위를 따라야 한다. 결과 파일은 기본적으로 정답이 없음을 명시한다.

완료 후 별도 정답 파일로 평가할 때는 아래 명령을 사용한다. 원래 보고서를 보존하고 `independent_assessments/`에 새 평가를 쓴다. 최소 5개 원본에서 정답 변화가 있는 경우 두 복원 설정 사이의 점수 변화 방향 일치율을 평가한다(기준 80%). 30-step이 더 좋다고 가정하지 않는다. 이 검사는 설정 변화에 대한 지표 반응이며, 특정 신규 모델의 우수성 검증을 대체하지 않는다.

```bash
bash scripts/run_metric_validation.sh --evaluate-truth /absolute/path/independent_truth.json
```

## 재개와 무결성

같은 명령을 다시 실행하면 완료된 작업·영상·개별 점수를 재사용한다. Python 환경을 단계마다 분리하고 GPU 모델은 순차 실행한다. 중단된 LGVSC 영상의 부분 실행은 `attempt_*/`에 보존하며 그 영상만 새 attempt에서 다시 시작한다. 이미 끝난 영상은 프로필·모델 경로·입력/출력 해시와 기존 9개 단계 검증을 통과해야 재사용된다.

선언한 코드·입력·설정의 변경, 결과 해시 불일치, 실행 오류는 즉시 정지시킨다. 같은 출력 경로의 동시 실행은 파일 잠금으로 차단한다. 실행이 정상 종료됐지만 과학적 탐지 기준을 통과하지 못한 경우에는 다음 검증으로 진행하며 실패/부족 결과를 그대로 남긴다. 단순 실행 완료를 연구 성공으로 표시하지 않는다. 최종 `summary.json`의 `execution_status`와 각 `report.json`의 지표별 판정을 구분한다.

코드·입력·결과는 SHA256으로 확인한다. 대용량 모델 파일과 설치 환경은 경로·크기·수정/변경 시각을 동결하여 일상적인 변경을 검출하며, 전체 가중치의 암호학적 재감사는 수행하지 않는다. 기존 v5 동결 소스와 결과 파일은 수정하지 않는다.

## 예상 시간

`--dry-run`은 기존 RTX 4080 기록(768쌍 시각 추출 약 41분, LGVSC 10초 입력 1개 약 2시간 18분)을 기준으로 현재 설정의 시간을 환산한다. 작업별 초기화, 픽셀 기준선, 저장·통계 비용을 범위에 포함한다. 기본 4초×12회 구성의 대략적인 실행 시간은 **약 13~26시간**이다. 모델 선택 시간의 입력 길이 의존성과 영상 복잡도 때문에 보장 시간은 아니다.

이는 명령 실행 시간이며 독립 복원 정답 구축, 신규 모델 개발, 논문 신규성 조사, GPU 경합, 실패 후 재실험 시간은 제외한다. 10초 영상 6~10개를 새로 준비하는 기존 추정과 입력 길이/복원 횟수가 다르다.
