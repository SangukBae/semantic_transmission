## 실제 확인 범위

60초 입력 60개와 120초 확장 6개, 합계 72분을 대상으로 **2초 간격 및 마지막 프레임
2,226장**을 시간 표시가 있는 72개 이미지 시트에서 직접 확인했다. 각 표본은 192×107로
축소되어 있다. 표집 범위는 처음부터 끝까지이지만 모든 프레임을 보거나 연속 재생한 것은 아니다.

의심되는 5개 입력은 변화량이 큰 위치의 인접 프레임 10쌍씩을 추가로 확인했다.
그중 3개 구간은 **4 fps**로 다시 확인했다. 추가 검수 시트는 8개다.
전체 디코딩은 입력 파일 검증이며, 디코딩한 모든 프레임을 시각 검수했다는 뜻은 아니다.

각 영상에 객체·동작·가림·촬영 구도·원본 편집 효과의 관찰 구간과 한계를 기록했다.
관찰 구간의 시작·끝은 사건의 정확한 발생·종료 정답이 아니다. 소리와 세부 객체 추적은 검수하지 않았다.
검수자는 기존 분류와 개요를 볼 수 있었으므로 기존 검토와 독립된 판정이나 블라인드 검수가 아니다.
자동 장면 후보와 AI의 같은 의견을 두 명의 독립 정답으로 세지 않는다.

## 확인한 주요 사항

| `tv_low_01_120s` | 60.75~61.25초, 64.25~64.75초에 도형 와이프를 확인하고 67.75~68초에 다음 와이프가 시작되는 것을 확인했다. 인터뷰 → 사진/글자 → 행사장으로 바뀐다. 자동 0.5 임계값의 0개 경계를 120초 전체 정답으로 사용할 수 없다. 120초 low 분류는 재검토 대상으로 남긴다. |
| `cs_low_05` | 2초 표집에서 여러 컷으로 의심했던 8~15초 변화는 4 fps 확인 결과 연속 팬·줌이었다. 7.125초 야외→실내 컷은 인접 프레임으로 확인했다. 처음의 추가 컷 의심을 철회했으며 분류를 바꾸지 않았다. |
| `cs_medium_07` | 2초 간격 표집이 50.083~51.875초의 관객 삽입 컷을 놓쳤다. 인접 프레임으로 확인했고 기존 자동 후보에도 이 경계가 있었다. AI 표집만으로 짧은 사건의 정답 완전성을 보장할 수 없다는 실제 사례다. |
| `cs_medium_10` | 21~25초 부근의 겹침과 36.75~39.5초 부근의 악기 근접 삽입·복귀는 원본 점진적 전환이다. 생성 잔상으로 오인하지 않아야 한다. |
| `tv_low_02` | 사람의 차량 내부 동작은 보이지만 구체적인 수리·공구 사용은 표본에서 확정하지 못했다. 기존 `vehicle_repair` 범주는 잠정으로 유지한다. |
| `cs_high_08`, `cs_high_10` | 대화의 얼굴 교차 편집이 많지만 대체로 같은 장소·인물 집합이다. shot 빈도와 의미적 scene 변화 난도를 분리한다. |
| `cs_low_08`, `cs_medium_03` | 카드·공중부양 마술의 변화와 연출이 원본에 있다. 물리적으로 특이한 장면이라는 이유만으로 복원 오류라고 분류하지 않는다. |

저전환 영상에도 사람·차량의 빠른 출입, 가림, 줌, 손과 도구의 상호작용이 있다.
고전환 영상에는 정적인 건축물 편집도 있으므로, 전환 유형만으로 전체 동작 난도를 설명하지 않는다.
자막·삽입 그림·검은 여백·카메라 흐림·반사·마술·입력의 압축 깨짐을 별도 태그로 남겼다.

## 상태와 사용 범위

- 입력 준비와 AI 검수 기록은 개발 실행의 참고 자료로 사용할 수 있다. 사람 두 명의 검수를
  마칠 때까지 장시간 실행 경로 개발을 기다릴 필요는 없다.
- `PASS_AI_SAMPLED_REVIEW_PACKAGE`는 66개 기록·입력 해시·확인한 증거 시트·시간 범위의
  구조 검사 통과다. AI 설명의 정확성 인증이 아니다.
- 원본 벤치마크의 manifest·분할·영상·독립 검수 작업은 덮어쓰지 않았다. 기존 분류의 변경은
  제안으로만 남겼으며, 채택할 경우 복원 결과를 보기 전에 새 프로토콜 버전으로 반영한다.
- **독립 사람 정답 준비, 모든 프레임 시각 검수, 복원 오류 평가, 완화 성능 검증은 완료가 아니다.**
  복원 영상의 Added/Missing/Distorted는 실제 복원 결과가 생긴 뒤 원본과 비교해야 한다.

## 재현

```bash
python scripts/etri_ai_source_review.py build
python scripts/etri_ai_source_review.py focus --ids cs_low_05 cs_medium_10 tv_low_01_120s tv_low_04 cs_medium_07
python scripts/etri_ai_source_review.py window --ids cs_low_05 --start 8 --end 15
python scripts/etri_ai_source_review.py window --ids cs_medium_10 --start 36 --end 41
python scripts/etri_ai_source_review.py window --ids tv_low_01_120s --start 60 --end 68
python scripts/etri_ai_source_review.py export
python scripts/etri_ai_source_review.py audit
```

`build/focus/window`는 증거 이미지만 만든다. AI 관찰은 실제 이미지를 보고 작성한
`notes.partial.json`에 따로 저장되어 있으며 `export`가 이를 포장한다. 스크립트를 실행했다고
자동으로 의미 검수가 끝나지는 않는다. 데이터 경로는 Git에서 제외되므로 다른 PC에서는 입력과
검수 산출물을 별도로 복사해야 한다.
