# FSO·EOI·UEP 관측·정답 정렬 수정 결과 — 2026-09-16

## 결론

**추적 대응·사건 정의 수정과 재평가는 완료했다. 자연 영상에서의 안정화는 아직 달성하지 못했다.**
기존 결과를 보존한 v6 개발 실험이다. 정상 자연 영상의 UEP 오경보 32/40과
실제 복원 12개의 UEP=1.0 포화가 남았다. ETRI 최종 지표 채택 판정은 보류한다.

## 구현과 실행

- [개발 프로토콜](METRIC_REVISION_PROTOCOL.md)을 저장한 뒤 코드·입력을 동결했다.
- RGB 관측 캐시에서 짧고 겹치지 않는 추적 조각을 연결하고, 프레임별 일대일 기하/특징 대응을 추가했다.
  동시에 나타난 두 객체를 한 객체로 합치거나 결측 프레임에 객체를 만들어 넣지 않는다.
- 사건은 화면 좌표의 중심 궤적·평활화·속도·각도·시간 기준을 동일하게 적용했다.
  카메라 독립적인 세계 좌표 의미는 별도 문제로 남겼다.
- EOI의 원본 순서 쌍 대응률이 80% 미만이면 null로 보류한다. 대응된 쌍에서 0이 나와도
  누락된 사건을 정상으로 인정하지 않는다.
- 자연 영상의 선택 객체 주석은 점수 계산 뒤의 쿼리 감사에만 사용한다. 관측기는 주석을 받지 않는다.
- **합성 1,800 + RX 180 + 자연 600 + 기존 실제 복원 12 = 2,592건**을 재평가했다.
  GPU 복원·SAM2/RAFT 재추론 없이 캐시를 재사용한 평가 실행은 **277.9초(약 4분 38초)**였다.
  코드 작성·시각 검토·보충 감사 시간은 포함하지 않는다.

## 같은 정답 정의에서의 합성 비교

원래 v5 세계 상태 정답과 새 화면 좌표 사건 정의를 혼합하면 비교가 왜곡된다.
따라서 추가 감사에서 렌더러 위치·가시성으로 새 정의의 정답을 재구성하고, 두 평가기의 저장 점수를
**동일 정답**과 비교했다. 카메라 조건은 알려진 아핀 변환을 주석 중심에도 적용했다.
이것은 같은 개발 자료의 보충 비교이며 새 사전 등록 평가가 아니다.

| 성분 | v5 AUC | v6 AUC | 해석 |
|---|---:|---:|---|
| FSO 잔존 존재 | 0.990 | 0.969 | 악화 |
| FSO 조기 등장 | 0.993 | 0.964 | 악화 |
| FSO 움직임 | 0.832 | 0.981 | 정의 정렬 후 구분력 개선, v6 관측률 약 94%로 부족 |
| FSO 방향 | 0.963 | 0.989 | 정의 정렬 후 개선 |
| EOI | 0.825 | 0.979 | 보류된 사례 제외 AUC; 양성 관측률 82.6%, 음성 85.2%로 부족 |
| UEP | 0.929 | 0.933 | 정상 오경보 1/120 → 0/120, 검출률 87.1% → 86.7% |

이 표의 v5 수치는 기존 프로토콜에서의 원래 채택 결과를 수정하지 않는다.
분류 문턱 0 초과를 진단에 사용했으며 v6의 새 독립 교정은 하지 않았다.
[동일 정답 비교 원자료](../outputs/metric_revision_20260916_v6/aligned_synthetic_truth.json).

RX 실험에서는 AUC **0.910**, 검출률 **81.9%**, 정상 오경보 **0/36**으로 기존과 동일했다.
원본·복원을 고정하고 수신 근거를 바꾸는 검증 효과는 유지됐다.

## 자연 영상의 남은 문제

UEP AUC는 0.612에서 **0.683**으로 올랐지만 정상 오경보는 **32/40으로 그대로**다.
밝기·질감·카메라·팔레트 변화 각각 8/8 경고, 무변형 정상 0/8 경고였다.

주석 객체와 실제 추출된 사건을 대응한 FSO 쿼리 감사에서도 관측 부족이 컸다.
움직임은 유효 정답 쿼리 235개 중 50개, 방향은 968개 중 200개에서 점수가 관측됐다.
관측된 일부의 AUC 0.961/0.925를 전체 성능으로 해석할 수 없다. 원본 단위 정답/관측 부족을 유지한다.

아래 그림은 각 행의 **원본 → 복원/외형 변형 → UEP 원인 영역(빨강) → 해당 마스크**다.
위 두 행은 실제 복원, 아래 네 행은 의미 오류를 넣지 않은 밝기 변화 대조군이다.

![UEP 경고를 만든 영역](../outputs/metric_revision_20260916_v6/review/unsupported_regions.png)

바닥의 작은 영역, 기존 사람 주변, 난간·도로 주변·옷 일부가 새 추적 객체로 분리됐다.
따라서 현재 병목에는 객체 대응뿐 아니라 **SAM2 부분/배경 영역을 의미 객체처럼 집계하는 문제**도 포함된다.
마스크를 더 잘 대응하는 수정만으로 이를 해결하지 못했다.

## 실제 복원 12개와 독립 시각 근거

- 원본·복원 각각 32개 평가 샘플과 수신 성공 슬롯을 직접 확인했다.
- [AI 시각 검토 기록](validation/2026-09-16-metric-revision-visual-review.json)을 작성하고,
  원본·복원·시간축·근거 이미지의 SHA256으로 [정답 파일](../outputs/metric_revision_20260916_v6/independent_truth.json)을 결합했다.
- 점수 추출기 출력은 정답 생성에 사용하지 않았다. 다만 검토자가 이전 v5 집계 결과를 알고 있었고
  사람 검수는 없으므로 완전 맹검·사람 독립 검증으로 주장하지 않는다.
- longboard·rallye의 두 복원 설정, **4개 영상(원본 2개)**에서 새 의미 객체가 보이지 않아 UEP 정답 0을 기록했다.
  나머지 8개는 중첩 잔상·먼 객체·표지판 변형 등의 불확실성 때문에 null로 보류했다.
  정답의 의미 객체 범위는 임의의 SAM 분할 영역과 같지 않다.
- 정확한 FSO 점유량/EOI 사건 시각·대응 정답을 거친 시각 설명만으로 만들지 않았다.
  FSO·EOI 수치 정답은 아직 확보되지 않았다.
- 이 4개 정상 영상에서도 **v5·v6 모두 UEP=1.0**이다. 양성 정답이 없고 독립 원본도 2개이므로
  AUC·모델 순위·채택 유효성을 판정하지 않는다.
- 실제 복원 전체에서 UEP 12/12가 여전히 1.0이다. FSO 움직임은 4/12, 방향은 3/12에서 계산됐고,
  EOI는 사건 대응률 부족으로 12개 모두 보류됐다. 이는 정확도 향상 증거가 아니다.

## 구현 확인과 재현

전체 회귀 147개와 이후 추가한 정답/보존 검사 4개를 통과했다. 수정 관련 12개 검사도 모두 통과했다.
원본 입력·결과, 관측 캐시, 2,592개 점수의 입력/결과 서명, 보고서 결합, 정답 근거 해시,
직접 쌍별 비교로 계산한 UEP AUC를 [검증기](../scripts/verify_metric_revision.py)로 확인한다.

저장소 루트에서 저장 점수를 재사용하거나 검사할 수 있다.

```bash
bash scripts/run_metric_revision.sh
PYTHONPATH=src .local/metric_v2_env/bin/python scripts/verify_metric_revision.py outputs/metric_revision_20260916_v6
```

보충 정답 비교와 시각 근거 대조는 아래 스크립트에 구현했다. 기존 결과를 덮어쓰지 않는다.

```bash

PYTHONPATH=src .local/metric_v2_env/bin/python scripts/assess_metric_revision_review.py --base outputs/metric_validation_20260916_v1 --output outputs/metric_revision_20260916_v6 --notes docs/validation/2026-09-16-metric-revision-visual-review.json
```
