# 17프레임 참조와 반올림 해제의 결합 실험

2026-09-28. [17프레임 참조 실험](ETRI_TAIL_REFERENCE_DIAGNOSIS.md)의 후속이다.
현재 상태: **세 창 × 네 조건 비교 완료**. 기존 두 조건을 검증·재사용하고 새 두 조건의
생성·평가 6건을 완료했다. 결합안은 사람 구간에 강한 흐림을 만들고 차량·차량 문에서도
각 단독 변경보다 우세하지 않았다. **기본 설정으로 채택하거나 60초 전체로 확대하지 않는다.**

## 목적과 네 조건

이전 실험에서는 참조 길이 제한과 마스크 위치 반올림 해제가 각각 일부 구간을 개선했지만,
객체 위치·형태 오류나 심한 깨짐이 남았다. 같은 잡음에서 두 변경의 상호작용을 확인한다.

| 조건 | 이전 생성 영상의 참조 | 마스크 위치 정렬 |
|---|---|---|
| baseline | 전체 구간 | `align=5` |
| no_rounding | 전체 구간 | `align=None` |
| tail17 | 마지막 17프레임 | `align=5` |
| combined | 마지막 17프레임 | `align=None` |

`align=None`은 끝 키프레임뿐 아니라 해당 마스크 함수의 참조·대상 시작 위치 모두에서
반올림을 해제한다. `conditioning_alignment='official_release'`를 유지하여
`endpoint_exact`가 참조 자르기까지 바꾸는 것을 방지한다. 구간 연결 정책, 기존 짧은
첫 구간의 왼쪽 패딩, 캡션·광류·수신 키프레임은 변경하지 않는다.

- 개발용 `tv_low_08`의 프레임 217~266(사람), 1303~1334(차량), 1400~1439(차량 문).
- AWGN 10 dB 수신 자료, 576×320, 24 fps, seed 2025, 확산 30단계.
- 같은 시드만 설정하지 않고, 저장된 기준선의 초기 잡음 텐서와 참조 인코딩 직전·생성 직전
  CPU/CUDA 난수 상태를 재사용한다. 실제 적용한 잡음·키프레임 잠재표현·난수 해시를 대조한다.
- 이전 실험의 완료 기록 13개와 코드·모델·환경을 검증한 뒤 baseline과 tail17의 6개 완료
  결과를 복사한다. no_rounding과 combined를 각 세 창에서 새로 생성·평가한다.
- 기존 no_rounding과 새 no_rounding의 MP4 해시도 비교해 재사용한 난수 상태의 영향을 확인한다.
- 추가 전송량 0. SKEM·캡션·광류·채널 송수신·학습을 재실행하지 않는다.

비교는 같은 조건으로 **새로 시작한 짧은 창**이다. 원래 60초 실행에서 누적된 생성 상태를
재현하지 않으며, 60초 전체 완화나 다른 영상·시드에서의 성능을 입증하지 않는다.

## 실행

```bash
bash scripts/check_etri_combined_reference.sh
```

결과: `outputs/etri_combined_reference_20260928`.
같은 명령으로 완료된 단계의 파일 해시를 검증하고 재사용한다. 실패한 단계는 부분 결과를
보관하고 다시 시작한다. 프로토콜이 달라지면 새 `--output` 경로가 필요하다.
기준선을 가져오는 `--source`는 완료된 17프레임 참조 실험 폴더다. 핵심 코드·모델·환경이
달라졌다면 기존 기준선과의 혼합을 거부하므로, 해당 환경에서 비교 기준선을 먼저 확보해야 한다.

## 결과와 판정

새 6건의 모델 생성·평가에 **34.44분**이 걸렸다. 아래 각 셀은 **PSNR dB / LPIPS**이다.
PSNR은 높을수록, LPIPS는 낮을수록 좋다. MP4 전체 프레임의 평균이다.

| 창 | baseline | no_rounding | tail17 | combined |
|---|---:|---:|---:|---:|
| 사람 | 16.443 / 0.400 | 16.109 / 0.430 | 16.282 / 0.383 | 16.951 / 0.434 |
| 차량 | 19.109 / 0.314 | 19.018 / 0.302 | 19.753 / 0.296 | 19.078 / 0.305 |
| 차량 문 | 16.593 / 0.537 | 19.812 / 0.311 | 16.667 / 0.488 | 17.974 / 0.348 |

키프레임 양끝을 제외하고 표적 구간의 **중간 생성 프레임만** 계산하면 다음과 같다.

| 원본 키프레임 구간 / 중간 프레임 수 | baseline | no_rounding | tail17 | combined |
|---|---:|---:|---:|---:|
| 사람 234→260 / 25 | 16.270 / 0.383 | 11.946 / 0.515 | 15.976 / 0.344 | 13.571 / 0.522 |
| 차량 1311→1331 / 19 | 16.699 / 0.350 | 17.394 / 0.318 | 17.774 / 0.319 | 17.496 / 0.323 |
| 차량 문 1409→1427 / 17 | 12.762 / 0.728 | 15.901 / 0.338 | 12.777 / 0.612 | 15.243 / 0.346 |

사람 구간은 전체 평균 PSNR만 보면 좋아지지만, 표적 중간 프레임에서는 PSNR과 LPIPS 모두
악화됐다. 전체 평균이 생성 구간의 실패를 가릴 수 있다. 차량은 tail17 단독이, 차량 문은
no_rounding 단독이 전체 PSNR·LPIPS에서 결합안보다 낫다. 이 결과는 한 영상·한 시드의
진단이며 통계적 우위나 전체 영상에서의 최적 방법을 뜻하지 않는다.

### 같은 27개 시점의 AI 관찰

앞선 실험과 동일하게 창마다 9개 시점을 원본 및 네 조건으로 확인했다. 시점·영역·불확실성은
[AI_REVIEW.json](../outputs/etri_combined_reference_20260928/AI_REVIEW.json)에 기록했다.

- **부분 개선:** 사람 9.5초, 차량 문 58.5·58.875·59.0·59.208초 표본의 추상 무늬가
  결합안에서 줄었다. 반올림 해제 단독에서도 나타난 개선이므로 결합만의 효과라고 하지 않는다.
- **새로운 실패:** 사람 9.917·10.0·10.167·10.417초 표본에서 결합안은 사람·울타리·나무를
  구분하기 어려운 강한 흐림을 만들었다. 10.0초의 압축 전 PNG도 직접 확인해 MP4 저장 전에
  이미 존재하는 문제임을 확인했다. 심한 흐림과 객체 Missing을 독립적으로 구분하지 않았다.
- **잔여 실패:** 차량의 확대·시점 차이가 남았다. 차량 문에서도 바퀴·손잡이의 위치와
  화면에 나타나는 시점이 원본과 다르며, 59.708초 표본의 문 각도·손잡이 위치 차이가 남았다.
- 앞뒤 키프레임 근처에서 객체가 다시 보인다고 중간 생성 프레임이 정상이라는 뜻은 아니다.
  원래 60초 실행에서 보인 차량 우측 이동 오류는 짧게 재시작한 기준선에서도 동일하게
  재현되지 않았으므로, 그 오류가 해결됐다는 주장을 하지 않는다.

**단일 AI의 방법 이름을 가리지 않은 표본 검토**다. 전 프레임의 Added/Missing/Distorted
발생률, 독립 정답, 연속 오류 지속 시간은 계산하지 않았다. 영역은 대략적인 관찰 위치다.

### 조건 위치 추가 점검

[MASK_AUDIT.json](../outputs/etri_combined_reference_20260928/MASK_AUDIT.json)은 실제 마스크
기록 48개(12구간 × 4조건)의 위치와 덮어쓰기를 별도로 집계한다. 의미 오류 개수는 아니다.

| 관측 항목 / 조건별 12구간 | baseline | no_rounding | tail17 | combined |
|---|---:|---:|---:|---:|
| 요청 위치와 다른 끝 키프레임 주입 | 8 | 0 | 8 | 0 |
| 조건이 같은 잠재 위치를 덮어쓰는 구간 | 3 | 1 | 3 | 1 |

반올림 해제 후에도 차량의 첫 구간 1303→1305에서는 잠재 시간축 길이가 1이다. 양끝
키프레임 조건이 모두 그 한 칸에 들어가 나중 조건이 앞 조건을 덮어쓴다. 한편 반올림 해제
조건은 12구간 중 8개에서 끝 키프레임을 5개 잠재 프레임 블록의 첫 위치가 아닌 내부에 넣는다.

로컬 Open-Sora VAE는 17개 영상 프레임/5개 잠재 프레임 단위로 나누어 복원하며, 나머지
구간은 별도의 시간축 패딩·제거를 사용한다. 따라서 **요청한 잠재 인덱스에 넣었다는 사실만으로
출력 영상의 해당 프레임이 정확하다고 할 수 없다.** 이 관측은 새 흐림의 원인을 확정한 것은 아니다.

다음 작업은 사람 234→260의 실패를 중심으로 **수신 키프레임의 단일 프레임 잠재표현이
VAE의 어느 시간 위치에 대응하는지, 17프레임 블록과 마지막 짧은 블록에서 어떻게 복원되는지**를
분리해 검사하는 것이다. 현재 결합안의 60초 확대, 다른 영상·시드 비교 및 새 수정안은 미실행이다.

## 재현성 확인

- 네 조건의 입력 파일과 수신 키프레임 잠재표현이 일치했다. 모든 12구간에서 초기 잡음,
  생성 난수 상태, 해당하는 이전 참조 인코딩 난수 상태가 조건 간 일치했다.
- 결합안의 이전 참조 9회 모두 17프레임→5잠재 프레임이었다. 처음부터 17프레임인 3회를
  제외한 6회에서 실제 참조 길이가 줄었다.
- 결합안은 12구간 중 6개에서 난수 재사용이 없었다면 초기 잡음이 달라졌을 것이다.
  단순히 같은 시드를 설정한 비교와 구분한다.
- 새 no_rounding의 세 MP4 모두 이전 실험과 SHA-256이 같았다. no_rounding과 combined의
  첫 PNG 18·9·10프레임은 각각 일치하며, 참조 자르기가 영향을 주는 이후부터 달라졌다.
- 같은 명령으로 **13개 단계를 모두 재사용**했다. 생성·평가를 다시 실행하지 않았다.
- 기존 60초 결과 3,275개 파일/15개 단계, 이전 반올림 실험 386개 파일/13개 단계,
  17프레임 참조 실험 407개 파일/13개 단계가 실행 전후 동일했다.
