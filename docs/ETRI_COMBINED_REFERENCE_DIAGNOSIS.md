## 세 창·네 조건 대응 비교 — 2026-09-28

사람(217~266), 차량(1303~1334), 차량 문(1400~1439) 프레임의 짧은 창을 새로 시작했다.
같은 AWGN 수신 키프레임·캡션·광류, seed 2025·30 steps, 초기 잡음과 대응 난수 상태를 사용했다.
추가 전송량은 0이다. 기존 60초 전체의 누적 생성 상태를 재현한 것은 아니다.

| 조건 | 이전 참조 | 위치 정렬 |
|---|---|---|
| baseline | 전체 이전 구간 | `align=5` |
| no_rounding | 전체 이전 구간 | `align=None` |
| tail17 | 마지막 17프레임 | `align=5` |
| combined | 마지막 17프레임 | `align=None` |

각 셀은 전체 창의 **PSNR dB / LPIPS**다. PSNR은 높을수록, LPIPS는 낮을수록 좋다.

| 창 | baseline | no_rounding | tail17 | combined |
|---|---:|---:|---:|---:|
| 사람 | 16.443 / 0.400 | 16.109 / 0.430 | 16.282 / 0.383 | 16.951 / 0.434 |
| 차량 | 19.109 / 0.314 | 19.018 / 0.302 | 19.753 / 0.296 | 19.078 / 0.305 |
| 차량 문 | 16.593 / 0.537 | 19.812 / 0.311 | 16.667 / 0.488 | 17.974 / 0.348 |

사람 표적 구간 234→260의 양끝을 뺀 25개 중간 프레임은 결합안에서 **PSNR 16.270→13.571, LPIPS 0.383→0.522**로
악화됐다. 전체 평균 PSNR만 보면 이 실패를 가릴 수 있다.

- **부분 개선:** 반올림 해제는 차량 문 표본의 심한 깨짐을 줄였다. tail17은 차량 일부를 개선했다.
- **새 왜곡:** 반올림 해제는 사람을 크게 확대했고, 결합안은 사람·울타리·나무를 구분하기 어려운 흐림을 만들었다.
  10초의 압축 전 PNG에도 있어 최종 MP4 저장만의 문제는 아니다.
- **잔여 오류:** 사람 형태, 차량 시점·크기, 문·손잡이 위치와 나타나는 시점 차이가 남았다.
- 원래 60초의 차량 우측 이동 오류는 짧게 재시작한 기준선에서도 동일하게 재현되지 않았다. 해결됐다고 주장하지 않는다.

같은 27개 시점의 AI 관찰이며 독립 정답·전 프레임 발생률은 미확보다.
**세 변경 모두 기본값 채택을 보류하고, 결합안의 60초 확대도 보류**한다.
다음은 단일 키프레임 잠재표현과 VAE의 17프레임/5잠재 프레임 블록·짧은 마지막 블록 대응 진단이다.

참조 길이가 바뀌면 같은 seed라도 난수 소비량이 달라진다. 실제 초기 잡음·수신 조건·난수 해시를 검증했으며,
결합안 12구간 중 6개는 재사용이 없었다면 초기 잡음이 달라졌을 것이다.
반올림 해제 뒤에도 아주 짧은 구간은 양끝 조건이 한 잠재 위치를 덮어쓴다. 잠재 위치 일치가 픽셀 시간축 정확성을 보장하지 않는다.
