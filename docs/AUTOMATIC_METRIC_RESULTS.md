# 사람 검수 없는 1차 작업 결과

작성일: 2026-09-12.

**자동 평가 체계와 첫 실험은 완료했다. 새 지표 후보 두 개는 채택 기준에 미달했다.**
따라서 1단계 연구의 최종 유효성·신규성 입증까지 완료된 것은 아니다.

## 무엇을 했나

- 코드가 오류를 넣고 정답을 기록하도록 만들었다. 시간 역순·정지·지연·순서 교환과
  객체 추가·누락·모양 왜곡을 검사한다. 사람 주석이나 VLM 판정을 정답으로 쓰지 않았다.
- 실제 영상 77개와 렌더링 장면 48개에서 **2,432개 사례**를 만들었다.
  조정용과 평가용을 원본 단위로 나눴고, 영상당 12개 시점을 평가했다.
- **RTE**는 시간 변화의 차이, **LSSD**는 화면 일부의 내용 차이를 측정하는 후보로 구현했다.
  PSNR·SSIM·LPIPS·CLIP과 시간축 기준선 tLP·tOF 등을 함께 계산했다.
- 기존 LGVSC 1개·SGD-JSCC 10개의 실제 복원을 진단하고, 차이가 큰 구간 **33개**를 자동 수집했다.
  이 구간은 확정된 의미 오류가 아니다.

## 핵심 결과

아래 검출률은 **코드로 넣은 오류를 찾은 비율**이다.

| 지표 후보 | 오류 | 검출률 |
|---|---|---:|
| RTE | 역순 | 47.3% |
| RTE | 정지 | 37.8% |
| RTE | 지연 | 100.0% |
| RTE | 순서 교환 | 43.3% |
| LSSD | 객체 추가 | 66.7% |
| LSSD | 객체 누락 | 66.7% |
| LSSD | 객체 모양 왜곡 | 60.4% |

대조군에 잘못 경보를 낸 비율은 RTE **10.8%**, LSSD **2.3%**였다.
대상 오류마다 검출률 80% 이상 등 사전 기준을 만족해야 하는데, 두 후보 모두 미달했다.

특히 **일부 구간만 틀어진 경우를 많이 놓쳤다.** 12개 평가 시점 중 3개에만 넣은
역순·정지·순서 교환을 RTE는 각각 0/67개 검출했다. 같은 길이의 객체 오류도
LSSD는 각각 0/32개 검출했다. 전체 평균을 내면서 부분 구간의 오류가 희석되는 문제가 드러났다.

일부 오류에서는 기존 SSIM·LPIPS·tOF가 더 잘 작동했다. 지표마다 오탐률이 다르므로
검출률만으로 순위를 정하지 않는다. **두 후보를 현재 모델 개선의 단독 목표나 최종 의미 오류
판정기로 채택하지 않는다.** 실패 사례를 남겨 다음 설계의 근거로 삼는다.

## 패키지 실행은 어디까지 확인했나

- WebVid 53개·Kinetics 14개의 서로 다른 길이를 입력 설정에 반영하는 검사를 통과했다.
- 새 데이터에서 만든 **9프레임·17프레임의 짧은 두 영상**을 LGVSC SKEM+DSA와 SGD-JSCC로
  각각 실제 복원했다. 네 결과 모두 공통 시간축 평가를 완료했다.
- SGD-JSCC 연결은 실제 BLIP2·JSCC·ControlNet·diffusion을 쓰는 프레임별 AWGN 경로다.
  기본 50 step 설정을 사용했다. 기존 ETRI의 int4 실험과는 조건이 다르다.
- 패키지 테스트 **33개 통과**, LGVSC 완료 영상 두 개의 재사용 검증 통과.
  고정된 원본–복원 한 쌍에서 특징 캐시를 지우고 점수를 두 번 계산했을 때,
  비교한 수치 31개의 최대 차이는 0이었다. 독립적인 생성 반복 실험은 아니다.

전체 67개 영상을 두 모델로 다시 복원한 것은 아니다. 객체 정답 실험은 도형 장면에 한정되며,
실제 사람·자동차의 환각률이나 복잡한 사건 순서의 정확도는 입증하지 않았다.
