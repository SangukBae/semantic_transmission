# ETRI 평가·보고 기준

갱신: **2026-09-28**. [메일](ETRI_FOLLOWUP_EMAIL_SUMMARY.md)의 요청을 실험·제출자료 기준으로 정리한다.
현재 완료 상태는 [과제 현황](README.md), 다음 작업은 [개발 계획](ETRI_DEVELOPMENT_PLAN.md)에 있다.

|---|---|---|---|
| R1 | 채널별 비교 제외, AWGN 검출·완화 집중 | E2·E4 | 공통 채널·입력·생성 조건과 비용 |

60초 이상은 확장 검토·달성 목표다. 5분은 비교 사례다.
영상 수·SNR·시드·합격 수치는 프로젝트가 평가 전에 정하며 메일의 확정 지시와 구분한다.

## 1. 비교 조건과 전송 비용

- 현재 주 조건은 AWGN 10 dB다. 입력 해시·시간축·해상도·공통 생성 설정·평가 코드를 맞춘다.
- 수신단만 바꾸면 동일 수신 패킷을 재사용한다. 생성은 가능한 범위에서 실제 초기 잡음·난수 상태까지 대응시킨다.
  시드가 같아도 난수 소비량이 달라지면 같은 잡음이 아닐 수 있다.
- 키프레임·설명을 추가하면 공통 패킷의 잡음을 대응시키고 추가분의 비용·잡음 규칙을 기록한다.
  같은 채널, 같은 예산 상한, 같은 실제 전송량은 구분한다.
- 수신단은 실제 받은 정보와 설치된 모델만 사용한다. 원본·수동 정답을 넣는 실험은 원인 진단으로 표시한다.
- 시각 심벌·메타데이터·rate index·부호화·패딩·갱신·사용한 재전송 비용을 합산한다.
  복원 MP4·복소수 저장 파일의 바이트를 무선 전송 비트로 간주하지 않는다. 제외한 물리 계층 비용도 명시한다.

## 2. 입력과 장시간 실행

원본 한 영상의 실제 연속 60초 이상을 사용한다. 반복·무관한 클립 연결·감속으로 길이를 늘리지 않는다.
낮은/일반/높은 장면전환에 객체 출입·배경 변화·동작 난도를 함께 기록한다.
shot 편집 경계와 의미적 scene 변화는 구분하며, 자동 경계 후보를 정답으로 쓰지 않는다.

현재 [입력 v1](ETRI_BENCHMARK_V1.md)은 60초 60원본과 120초 확장 6개, 개발/교정/평가 18/12/30이다.
396개 예정 작업(66입력 × 3채널 시드 × 기준선/완화)은 실행 완료 수가 아니다.
같은 원본의 확장·관련 콘텐츠는 같은 분할에 두고, 결과를 본 영상은 개발 자료로 관리한다.

- 길이를 보존하는 별도 [60초 실행기](ETRI_60S_RUN.md)를 사용한다. 기존 10초/16초 프로필과 구분한다.
- 내부 구간 분할 시 원본 시간축, 참조·상태 전달, 경계 중복·누락, scene 초기화 정책을 검사한다.
- 짧게 재시작한 창의 비교는 60초 전체의 누적 상태 검증으로 보고하지 않는다.
- 실제 출력 프레임·PTS·길이, 단계별 시간·최대 메모리·실패 위치·재개 범위를 기록한다.
  입력 준비나 짧은 smoke 통과만으로 장시간 복원 완료를 판정하지 않는다.

## 3. 오류 정답과 검출·완화

Added는 원본에 없는 내용 추가, Missing은 존재해야 할 내용 누락, Distorted는 형태·속성·동작·관계 왜곡이다.
정상 가림·퇴장·원본의 편집·마술 등을 생성 오류로 오인하지 않는다.
drift·깜빡임·속도·사건 순서·이전 장면 잔류는 추가 태그로 기록한다.

- 시각/프레임, 객체·동작, 가능한 영역, 지속시간, 심각도·확실성, 근거 이미지를 기록한다.
  Missing은 원본 영역을 사용할 수 있으며 좌표 기준을 명시한다.
- 점수 계산에 쓴 검출기·VLM의 출력을 정답으로 재사용하지 않는다.
  현재 AI 단독·비맹검 표본 관찰은 탐색 근거이며 독립 정답·전 구간 발생률이 아니다.
- 입력 v1의 정식 검수는 서로 다른 두 검수자의 독립 확인과 불일치 조정을 기준으로 한다.
  방법 이름을 가린 복원 비교를 수행하고, 오류 0도 전 구간 확인을 명시한다. 빈 주석은 미평가다.
- 관측 불가·정답 부족은 보류하며 정상 점수 0으로 채우지 않는다. 표본 관찰 창을 확정 오류 지속시간으로 쓰지 않는다.
- 검출은 오탐·미탐·관측률, 완화는 잔존 오류·새 오류·지속시간으로 각각 평가한다.
  PSNR·LPIPS 개선만으로 할루시네이션 감소를 결론 내리지 않는다.

## 4. 시간축·씬 체인지·학습 검토

| 검토 대상 | 평가할 내용 |
|---|---|
| 저전환 영상 | 마지막 수신 키프레임 이후 경과 시간별 drift·깜빡임·객체 유지 |
| 중·고전환 영상 | 독립 장면 경계와 검출·키프레임/패킷 생성·수신·적용 시각, 이전 참조 초기화 |
| 검출 누락 대안 | 실제 누락과 통제 누락/지연에서 대체안 유무 비교, 잔존 오류·새 왜곡·갱신 비용 |
| 동적 정보 | 객체별 속도·방향·등장/퇴장·동작 설명의 누락, 보강 후 수신단 반영과 추가 비용 |
| 학습 이력 | 모듈별 체크포인트·학습 자료·시간축 학습 목적·로컬 추가 학습 여부·미확인 항목 |

최대 간격·주기적 갱신·재검사·수신 프레임 기반 출력은 검증 대상 후보다.
키프레임 선택 성공을 씬 체인지 검출 성공과 동일시하지 않는다.
NTSCC 이미지 학습과 Open-Sora 영상 생성기의 학습을 구분한다.
조건 보강과 동영상 미세조정의 필요성은 실패 원인을 분리한 뒤 판단한다.
[구조·학습 검토 항목](MODEL_ARCHITECTURE.md)

## 5. 결과와 제출자료

1. **실행 기록:** 원본·모델·코드·설정·패킷 해시, AWGN·시드, 시간·메모리·실패·전송 비용.
2. **비교 영상:** 같은 시간축의 원본/완화 전/완화 후. 정량 평가는 비교용 재인코딩 영상과 구분한다.
3. **오류·갱신 기록:** 유형·시각·영역·판정 상태, 패킷 갱신·초기화·대체안 로그.
4. **판정:** 성공·미완화·새 왜곡·실행 실패·보류를 모두 포함한다. 사례 선정 방법과 전체 수를 명시한다.

최종 방법·문턱·허용 손실·지표·비교 조건은 평가 전에 고정한다. 유형·데이터셋별 결과와 함께
원본 또는 관련 콘텐츠 그룹 단위의 대응 차이·신뢰구간을 보고한다. 프레임·시드·120초 확장을 독립 원본 수로 세지 않는다.
영상 평균이 짧은 실패를 가리지 않도록 표적 중간 프레임과 오류 지속량도 확인한다.

**실행 완료 / 오류 주석 완료 / 완화 효과 / 길이·유형 충족 / 지표 유효성·신규성 / 전송량 절감**을 따로 판정한다.
과거의 동결 프로토콜·판정은 당시 기준으로 보존한다. 현재 기준 개정으로 과거 실패를 통과로 바꾸지 않는다.
