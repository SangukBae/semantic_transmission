# 단기 LGVSC 개선 방법 선정 근거

개정일: 2026-09-21. 시간이 제한된 상황에서 **로컬 개선 관측 → 기존 구현 재사용 → ETRI가 지적한 실패 원인과의 연결** 순으로 방법을 골랐다. 아래 기대효과는 연구 판단이며 성공 확률이나 60초 성능을 보장하는 수치가 아니다.

**먼저 최대 1초 키프레임 보강을 적용하고, 씬 경계의 조건·참조 갱신을 추가한다. 실제 전송한 저해상도 영상은 의미 오류 검수를 통과할 때만 보강한다.** 실행 범위는 [단기 실험안](ETRI_LGVSC_HALLUCINATION_EXPERIMENT_PLAN_2026-09-21.md), 재사용 위치는 [코드 감사](ETRI_HALLUCINATION_CODE_AUDIT_2026-09-21.md)에 정리했다.

## 1. 순위를 바꾼 로컬 근거

모두 기존 짧은 영상 결과다. 이번 개정에서 새 복원은 실행하지 않았다. PSNR은 높을수록, LPIPS는 낮을수록 좋다.

| 비교 | 실제 관측 | 단기 판단 |
|---|---|---|
| ETRI 10초: 기존 → 정렬+최대 1초 키프레임 | PSNR **19.7081→23.8337**, SSIM **0.7683→0.8439**, LPIPS **0.3553→0.2957**; 채널 사용량 **4.091배** | 큰 화질 개선의 직접 근거. 우선 후보로 채택하되 전송량 증가와 정렬 결합 효과를 명시 |
| WebVid 14초: 기존 → 같은 키프레임 보강 조합 | PSNR **21.6592→21.9051**, SSIM **0.6803→0.7132**; LPIPS **0.2838→0.3055**로 악화; 전송량 **1.419배** | 모든 영상에서 크게 개선된다고 일반화할 수 없음. 객체·행동 검수 필요 |
| ETRI: 동일 예산 상한의 균일 추가 → 적응형+저해상도 보강 | PSNR **21.1449→24.1065**; LPIPS **0.3281→0.3438**로 악화 | 큰 저주파 오차 감소 가능성. PSNR만으로 주력 채택하지 않음 |
| WebVid: 위와 같은 예산 비교 | PSNR **21.1307→22.4256**; SSIM **0.6722→0.6548**, LPIPS **0.2880→0.3149**로 악화 | 위치·형태 개선과 흐림·잔상·객체 오류를 함께 확인한 뒤 조건부 사용 |

마지막 두 비교의 실제 채널 사용량은 ETRI **135,575→131,568**, WebVid **832,481→825,914**다. 공통 예산 상한 아래의 비교이며 사용량이 정확히 같지는 않다. 키프레임 선택과 보조영상이 함께 바뀌었으므로 저해상도 보정만의 효과로 분리할 수 없다. 해당 실행은 **검증 1·2만 완료**, 별도 5편 검증 결과는 없고 할루시네이션 검수는 `PENDING`이다.

## 2. 가장 먼저 적용할 두 방법

**최대 키프레임 간격 축소:** 기존 수신 조건만으로 중간 사건을 추정해야 하는 시간을 줄인다. 이미 실제 NTSCC·AWGN 전송과 복원 코드가 있고, ETRI 영상에서 개선 폭이 컸다. 기본은 1초, 전송·처리 예산을 넘으면 개발 단계에서 2초로 조정한다. 키프레임이 이미 조밀하거나 수신 프레임 자체가 틀린 영상에서는 이득이 작을 수 있다. 정렬만으로 전체 화질이 좋아진 것은 아니며 기존 결합 recipe를 재사용하는 결정이다.

**씬 경계별 조건·참조 갱신:** 서로 다른 장면을 하나의 생성 구간으로 연결하거나 이전 장면의 caption·생성 참조를 넘기지 않도록 한다. 메일의 씬 체인지·갱신 실패 문제에 직접 대응한다. 로컬 효과는 아직 확인되지 않았으므로 ‘높은 개선률이 입증된 기법’으로 표시하지 않는다. [TransNet V2 저자 저장소](https://github.com/soCzech/TransNetV2)의 경계 검출을 활용할 수 있으나, 경계 양쪽 키프레임·caption 재추출·decoder 초기화 연결은 별도 구현이다. 검출 누락의 대체안은 최대 간격 제한과 주기적 의미정보 갱신이다.

이 두 방법은 모델 교체·재학습 없이 현재 경로에 적용할 수 있다는 점에서 우선한다. 별도의 복잡한 환각 검출기를 먼저 완성할 필요는 없다. 대신 원본 기준 오류 위치·유형과 자동 검출의 실제 범위를 명확히 보고한다.

## 3. 저해상도 보조영상은 왜 조건부인가

수신 정보에 사건 자체가 없으면 생성기만 바꿔도 진실을 확정하기 어렵다. 매 프레임의 작은 영상을 실제 전송하면 중간 움직임·큰 구조에 대한 관측을 보충할 수 있다. 로컬 코드는 72×40 영상을 실제 채널로 전송하고 생성 영상의 저주파를 후처리로 보정한다. 이는 학습된 diffusion 조건 주입이나 SparkVSR의 재현이 아니다.

[SparkVSR 원문](https://arxiv.org/html/2603.16864v1)은 전체 LR 영상과 희소 HR reference를 함께 사용한다. 희소 키프레임만 있는 LGVSC와 입력 조건이 다르며, 참조 강도를 높일 때 지각 품질과 원본 충실도가 엇갈리는 결과도 보고한다. 여기서는 **추가 관측의 중요성**만 참고하고 외부 모델 전체는 도입하지 않는다.

기존 생성물의 보정 전후를 비교해 실제 객체·동작 오류가 줄고 정상 구조가 유지될 때만 추가한다. 잘못된 고해상도 객체가 그대로 남거나 흐림·잔상이 늘면 제외한다. 송신 원본의 LR 영상을 수신단에서 무전송으로 읽는 실험은 oracle이며 제출용 성능에서 분리한다.

## 4. 기본 조합에서 뺀 방법

| 후보 | 이번에 우선하지 않는 이유 |
|---|---|
| 정렬만 적용 | ETRI 전체 PSNR 19.7081→19.4705, WebVid 21.6592→21.3507. 단독 개선의 근거가 없음 |
| 행동 caption 확대·복잡한 이벤트 패킷 | ETRI에서 1초 보강에 수동 caption까지 더하면 PSNR 23.8337→23.7729, LPIPS 0.2957→0.3089. 자동 caption 갱신은 유지하되 내용 확대는 누락 사례가 남을 때만 시험 |
| 현재 적응형 키프레임 삽입 | 짧은 두 영상의 공통 예산 비교에서 균일 추가보다 PSNR·SSIM·LPIPS가 모두 나빴음. 이 결과는 해당 로컬 알고리즘에 한정 |
| 수신 anchor 잔차 후처리 | PSNR 개선은 ETRI 약 +0.11 dB, WebVid 약 +0.21 dB로 작고 WebVid LPIPS는 악화. 큰 개선의 주력으로 삼기 어려움 |
| SparkVSR·STCDiT·SeedVR2·FlashVSR·STAR 도입 | 입력 adapter·가중치·메모리·학습 조건 검증 부담. 현재 환경의 의미 오류 감소 근거가 없음 |
| DynamicDPS·RPU 직접 이식 | NTSCC 심벌 관측과 Open-Sora rectified-flow에 맞춘 별도 설계 필요 |
| HalluGen·sFRC 검출기 전이, RAR 반복 제어, CFG 탐색 | 추가 교정·구현이 필요하거나 로컬 개선 근거가 없음. 첫 비교영상을 지연시키지 않음 |

## 5. ETRI 요구에서 유지할 것

실제 연속 60초 이상·장면전환 3유형, 동일 입력/AWGN의 전후 영상, Added/Missing/Distorted 표시, 성공·미완화·새 왜곡, 키프레임에서 멀어질 때의 drift와 검출 누락 사례는 유지한다. 시험영상은 내부 검증에 사용한다. 5분·재학습·특정 개선율은 메일의 확정 요구가 아니다.

학습 질문은 모듈별로 답한다. [고정 모델 ID](../../configs/models.json)와 [모델 구조](../MODEL_ARCHITECTURE.md)를 근거로 NTSCC의 이미지 코덱 학습, PLLaVA·Open-Sora의 영상 모델 이력, 프로젝트의 추가 학습을 구분한다. ‘영상 모델 사용’만으로 동작 정보의 충분성을 주장하지 않는다. 현재 PLLaVA는 구간당 4프레임을 표집하고 광류는 스칼라로 요약하므로, 짧은 구간 재추출 후에도 동작·방향·등장/퇴장을 놓치는지 확인한다.

기존 새 지표 연구는 유지하되 이번 결과의 주 판단은 독립 원본 대조다. FSO·UEP·EOI의 기존 한계를 유지하고 검출기 출력으로 정답을 만들지 않는다. 일반화·새 지표 신규성은 첫 예비 시연과 별도 검증한다.
