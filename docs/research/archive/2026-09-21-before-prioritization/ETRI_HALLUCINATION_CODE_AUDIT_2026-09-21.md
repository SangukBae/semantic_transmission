## 검증 범위와 미확인 항목

- 커밋별 URL·선택한 줄의 내용·확보 파일 SHA-256을 로컬 사본과 대조했다. 원문 버전·파일 해시·로컬 요구사항 해시를 아래 JSON에 저장했다.
- 이 감사에서 가중치를 실행하거나 학습하지 않았다. 메모리 사용량·성능 수치·전체 환경 설치 성공은 확인한 항목이 아니다.
- HalluGen의 별도 reference-free detector 전체 재현 경로와 가중치는 이번 선택 파일 감사로 확인되지 않았다. SHAFE 실행 성공을 그 검출기 재현으로 바꾸지 않는다.
- RPU와 2026-08-27 Multi-Modal References 신작은 원문을 읽었지만 해당 논문의 공식 구현을 확인하지 못했다. ZVRD 선행작 코드를 신작으로 대체하지 않는다.
- SAVER·VidHalLoc는 픽셀 복원 모델의 오류 감소를 직접 입증하는 연구가 아니다. SAVER는 원문·저장소 설명 확인 수준이고, 위 9개 코드 감사 저장소에 포함되지 않는다.
- 라이선스·가중치 조건은 구성 요소마다 다를 수 있다. JSON의 소스 목록은 실행·재배포 허가 또는 전체 라이선스 감사 결과가 아니다.
