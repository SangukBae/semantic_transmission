## 어떤 연구인가

영상 전체 대신 **대표 프레임과 장면 설명을 전송하고, 받은 정보로 영상을 생성·복원**하는 연구다.
전송량을 줄이면서도 원본의 객체·동작·시간 흐름을 보존하는 것이 목적이다.
생성 모델이 없는 객체를 만들거나, 있던 객체를 지우거나, 동작·형태를 바꾸는 오류를 줄여야 한다.

- **키프레임:** 복원의 기준으로 선택해 전송하는 영상 프레임.
- **Semantic Packet:** 캡션·움직임 요약·키프레임 위치 등 복원에 필요한 의미·보조정보 묶음.
- **할루시네이션:** 원본 대비 Added(추가)·Missing(누락)·Distorted(왜곡) 오류. 정상 가림·퇴장과 구분한다.

처리 흐름은 **영상 → 키프레임·구간 설명 추출 → AWGN 송수신 → 생성 복원 → 오류·화질·비용 평가**다.
모듈별 역할은 [모델 구조](MODEL_ARCHITECTURE.md)에 있다.

## 기존 네 목표와 이메일의 연결

| 목표 | 해결하려는 문제 | ETRI 후속 메일과의 연결 |
|---|---|---|
| **E1 시간축·영상 신뢰성 확보** | 동작·방향·사건 순서를 보존하고 drift·깜빡임을 줄임 | 연속 60초 이상, 장면전환 저/중/고, 씬 체인지·패킷 갱신·검출 누락 대안, 동적 의미정보 |
| **E2 생성 복원의 할루시네이션 검출·완화** | 객체·내용의 추가·누락·왜곡을 검출하고 줄임 | AWGN에서 동일 입력·채널의 원본/완화 전/완화 후, 성공·실패·새 왜곡 제시 |
| **E3 의미 전달 평가 체계의 신뢰도 확보** | 실제 오류와 개선을 측정할 새 지표 1~2개 개발 | 오류 시각·영역·유형 근거, 독립 정답으로 검출과 완화 효과 확인 |
| **E4 의미 신뢰성을 유지하면서 전송량 절감** | 같은 의미 정확도에서 전송 비용을 줄임 | 추가 키프레임·동적 설명·갱신 비용까지 포함한 비용–효과 비교 |

메일은 **기존 방향을 유지하며 E2에 집중**하라는 요청이다. 채널 종류별 비교는 현재 범위에서 제외한다.
5분은 비교 사례이며 필수 길이가 아니다. 새 지표 1~2개는 기존 개발 목표이며 메일의 추가 지시가 아니다.

| 새 지표 | FSO·EOI·UEP 구현·재평가 | 자연 영상 오경보·관측 부족·점수 포화 해소와 유효성·신규성 입증 |
| 씬 체인지·동적 정보 | 현재 구조와 평가 기준 정리 | 실제 검출·갱신·누락 대안, 정보 보강 효과, 모듈별 학습 근거 정리 |
| 전송량 | 시각·메타데이터 전송량 계측. 최근 수신단 변경의 추가 전송량 0 | 의미 정확도를 유지하는 전송량 절감 효과 입증 |

**396개 대응 작업은 계획된 수량**이다. [입력 설계](ETRI_BENCHMARK_V1.md) · [AI 검수](ETRI_AI_SOURCE_REVIEW.md)

## 최신 실험에서 배운 점

**60초 실행은 성공했지만 복원 품질과 의미 오류가 남았다.** PSNR 14.85 dB, SSIM 0.648, LPIPS 0.388이다.
키프레임 위치보다 중간 생성 프레임의 품질이 낮아 생성 조건 전달을 우선 진단했다.
캡션·광류 109행의 구간 대응은 정상이며, 설명 내용의 누락·충돌과 조건 시간 위치 변경은 추가 검증 대상이다.

| 같은 세 창에서 비교한 변경 | 결과와 결정 |
|---|---|
| 조건 위치 반올림 해제 | 차량 문 창 PSNR 16.59→19.81 dB, LPIPS 0.537→0.311. 사람에 새 확대 왜곡 발생; 일괄 채택 보류 |
| 이전 생성 영상의 마지막 17프레임 참조 | 차량 일부 개선, 사람 형태 오류·차량 문 깨짐 잔존; 개발 후보 유지 |
| 두 변경 결합 | 사람에 강한 흐림 발생, 각 단독 변경보다 일관되게 우세하지 않음; 기본값 채택·60초 확대 보류 |

같은 수신 데이터와 대응 생성 잡음을 사용했지만, **한 영상·한 시드의 짧게 재시작한 구간**이다.
원래 60초의 누적 상태를 재현한 실험이나 할루시네이션 감소율 검증은 아니다.
[조건 진단](ETRI_CONDITIONING_DIAGNOSIS.md) · [17프레임 참조](ETRI_TAIL_REFERENCE_DIAGNOSIS.md) ·
[최신 결합 실험](ETRI_COMBINED_REFERENCE_DIAGNOSIS.md)

실행 비용도 과제다. 원래 SKEM에 23시간 19분, 이를 재사용한 뒤 나머지 실행에 112.44분이 걸렸다.
새 지표는 별도 개발 중이며, UEP의 정상 자연 영상 오경보 32/40과 실제 복원 12/12의 점수 포화가 남아 있다.
