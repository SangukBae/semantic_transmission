[평가 기준](ETRI_FOLLOWUP_PROTOCOL.md)

## 개발 목표

기존 **E1 시간축·영상 신뢰성, E2 할루시네이션 검출·완화, E3 평가 체계 신뢰성, E4 전송량 절감**을 유지한다.
현재 우선순위는 AWGN에서 실제 생성 오류를 줄이고, 연속 60초 이상·장면전환 3유형에서 효과와 실패를 확인하는 것이다.
새 지표 1~2개는 모델 개선과 함께 개발하며, 최종 지표 채택을 기다리느라 완화 실험을 미루지 않는다.

## 현재 출발점

- 60초 60원본과 120초 확장 6개를 준비했다. 독립 정답은 미완료다.
- 저전환 개발 영상 한 편의 전체 60초 복원에 성공했다. 중·고전환과 전체 완화 평가는 남았다.
- 같은 영상의 짧은 세 창에서 반올림 해제·17프레임 참조·결합안을 비교했다.
  부분 개선과 새 왜곡이 함께 나타나 모두 기본값 채택을 보류했다.
- 지표 후보 FSO·EOI·UEP는 자연 영상 안정성과 실제 복원 유효성이 미입증이다.

상세 수치와 완료 근거는 [현황](README.md), 개별 실행 이력은 [실험 목록](EXPERIMENT_INDEX.md)에서 관리한다.

## P0 — 지금 수행할 한 가지 실험

**수신 키프레임의 잠재표현이 VAE 시간축의 어느 위치에 복원되는지 확인한다.**
최근 결합안에서 악화된 사람 구간(원본 프레임 234→260)을 우선 대상으로 한다. E1·E2에 해당한다.

1. 한 프레임 키프레임 조건을 17프레임 블록과 마지막 짧은 블록의 각 위치에 넣었을 때 실제 복원 위치를 확인한다.
2. 끝 키프레임·이전 참조 조건의 겹침과 덮어쓰기를 기록하고, 위치 반올림·참조 길이 효과를 분리한다.
3. 기존 수신 데이터·잡음·생성 설정을 유지하며 원본/기준선/변경안과 표적 중간 프레임을 비교한다.

**산출물:** 시간 위치 대응표, 재현 가능한 실패 사례, 수정 가설 하나와 대응 비교 근거.
**진행 조건:** 표적 오류 감소와 새 왜곡 여부를 함께 확인한 후보만 장시간으로 확장한다.
개선이 불분명하면 원인 진단에 머물며, 현재 결합안을 60초로 확대하거나 기본값으로 바꾸지 않는다.
[이 판단의 근거](ETRI_COMBINED_REFERENCE_DIAGNOSIS.md)

## P1 — 후보가 확보되면 이어갈 작업

| 순서 | 작업 | 목표 연결 | 완료 근거 |
|---|---|---|---|
| 1 | 동일 60초 개발 영상의 전체 기준선/완화 대응 비교 | E1·E2·E4 | 누적 상태를 유지한 세 영상, 잔존·새 오류, 전송량·시간·메모리 |
| 2 | 중·고전환 개발 영상으로 확장 | E1·E2 | 유형별 실제 처리 길이, drift·깜빡임, 장면 경계 오류·실행 실패 |
| 3 | 씬 체인지 검출·키프레임/패킷 갱신과 누락 대안 비교 | E1·E2·E4 | 경계·갱신·초기화 로그, 실제 누락 및 통제 누락 사례, 대체안의 효과·부작용·비용 |
| 4 | 개발·교정 후 방법을 고정하고 미사용 평가 영상에서 검증 | E1~E4 | 독립 정답, 유형별 대응 결과와 불확실성, 성공·실패·새 왜곡 사례 |

최대 키프레임 간격, 주기적 의미정보 갱신, 별도 변화 신호, 수신 프레임 기반 출력은 누락 대안 후보다.
기존 키프레임 선택만으로 씬 체인지 대응이 검증됐다고 보지 않는다.

## 함께 준비할 근거

- **E3 지표:** 실제 목표 오류 1~2개를 선정하고 모델 변경과 함께 측정법을 개발한다.
  관측 실패·정답 부족·점수 포화를 구분하고 독립 근거로 유효성과 신규성을 검증한다.
  [지표 개발 지침](METRIC_DEVELOPMENT_STRATEGY.md)
- **학습·동적 정보:** 모듈별 체크포인트의 이미지/동영상 학습 근거와 로컬 추가 학습 여부를 정리한다.
  현재 구간 캡션·광류 요약이 놓치는 객체·속도·방향·사건 시각을 확인한 뒤, 정보 보강 실험을 설계한다.
  [현재 구조와 확인할 항목](MODEL_ARCHITECTURE.md)
- **E4 비용:** 키프레임·캡션·광류·갱신 신호·부호화 비용을 계측한다. 같은 의미 정확도에서의 절감과
  같은 예산에서의 정확도를 구분한다. 수신단 변경의 추가 전송량 0만으로 절감 목표 달성을 주장하지 않는다.
- **실행 비용:** 전처리·모델 재사용은 출력 동일성을 확인한 범위에서 적용한다.
  속도 개선은 위 실험을 지원하며, 품질 손실과 의미 오류 증가를 별도로 점검한다.

## 이후 후보와 종료 기준

학습형 키프레임 선택기, 동적 설명 확대, 동영상 미세조정, 생성 가속은 후속 후보다.
현재 오류 원인과 비용·효과 근거를 확보한 뒤 착수 여부를 정한다. 학습형 선택기는
[검토안](research/ETRI_LGVSC_LEARNED_KEYFRAME_SELECTOR_PROPOSAL_2026-09-21.md)이며 구현·학습 완료 기록이 아니다.

실행 완료, 오류 주석 완료, 완화 효과, 지표 유효성·신규성, 전송량 절감은 각각 판정한다.
실제 연속 60초 이상과 세 유형을 평가하되 5분이나 특정 영상 수를 메일의 필수 조건으로 확대하지 않는다.
채널 종류별 비교·Rayleigh/SDR·안전 중요 응용 인증은 현재 완료 조건에 포함하지 않는다.
