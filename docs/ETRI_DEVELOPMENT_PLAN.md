## 현재 기본 방식 — FC-LGVSC + 수신단 구현 오류 수정

- **이름:** FC-LGVSC (Faithful Caption-guided LGVSC). 원본에 충실한 캡션 v2로 영상 복원을 유도하는 LGVSC 파생 방식. [간단한 구조](MODEL_ARCHITECTURE.md#fc-lgvsc)
- **결정:** 2026-09-30 캡션 v2 채택. 2026-10-01 사용자 요청으로 조건 충돌 방지·짧은 구간 시간표 수정 추가.
- **후보:** AI가 객체·동작·구도 변화를 확인; 시작·끝, 확인한 등장·퇴장·가림 변화·컷 전후는 필수 보존.
- **중복 판단:** 나머지 후보를 최신 선택 프레임과 SKEM으로 비교; `P(No)−P(Yes)>0.35`이면 선택.
- **간격:** 선택 없이 1초가 지나면 보강하고 비교 기준도 갱신. 1초·0.35는 현재 실험값이며 최적값은 미확정.
- **캡션:** 구간별 원본 표본 4장을 보고 AI가 영어로 작성; 최대 6문장·80단어.
- **작성 기준:** 객체·위치·크기·방향·보이는 부분·가림·확인되는 변화·흐림을 구체적으로 기록. 보이지 않는 사건·속성·분위기는 추측하지 않음.
- **복원:** 저장된 선택·캡션 → UniMatch 움직임 추출 → AWGN 전송 → LGVSC 복원·평가. PLLaVA 설명 생성은 생략.
- **참조:** 각 직전 생성 구간의 마지막 17프레임을 먼저 잘라 압축. 짧으면 첫 프레임을 앞에 반복; 위치 보정 `align=5`는 유지.
- **조건 충돌 방지:** 시작·끝 조건이 겹치면 끝 키프레임을 마지막 압축 위치로 이동. 충돌 없는 구간의 기존 배치 유지.
- **시간표 수정:** 생성 입력 2~16프레임에서 길이를 0으로 계산하던 오류 수정. 나머지 길이의 기존 계산 유지.
- **T5:** 보행 검증과 동일한 CPU FP32 저장값 재사용. 생성기 BF16·30단계 유지; BF16 대비 정밀도 단독 우위를 뜻하지 않음.
- **잡음:** 두 수신단 수정의 대조는 직전 FP32의 VAE·초기·반복 생성 잡음과 해시 일치, 입력·전송량 동일. 처음 LGVSC와의 비교는 선택·캡션·잡음 등이 함께 달라 개별 효과가 분리되지 않음.
- **검증:** 두 수정 결합으로 보행 10초 완료. 초반 모자이크 해소·직전 대비 평균 5지표 개선; 후반 일부 악화, 생성 시간 약 10% 증가. [결과](ETRI_COMBINED_REFERENCE_DIAGNOSIS.md#schedule-fix-person)
- **입력:** `tv_low_08` 60초, `person_walk` 10초, `single_subject` 14.04초, `candle_flowers` 7.54초. 모두 AWGN 10 dB·기존 FP32 수신 자료 재사용.
- **범위:** 새 기본 경로로 4편 전체 복원·기존 LGVSC 비교 완료. 평균 개선과 새 왜곡 공존; 중·고전환 확대·독립 완화 효과는 미검증. [결과](ETRI_COMBINED_REFERENCE_DIAGNOSIS.md#fc-lgvsc-four)
- **기존 근거:** 참조 변경 전 v2는 SKEM·PLLaVA 대비 전송량 −30.0%, 평균 지표 소폭 개선. 후속 참조·T5 변경은 일부 오류 개선·새 왜곡이 공존하며 전송량 동일.
- **실행:** `bash scripts/reconstruct_fc_lgvsc.sh`; `--video person_walk`로 보행 선택. 기존 명령·완료 결과는 비교용 보존. [실행 안내](RUN_GUIDE.md#default-method) · [캡션 원문](../configs/captions/tv_low_08_faithful_v2.json)

## 지금 할 작업 — 2026-10-03

**다음 실험은 한 요소씩 비교하고, 자동 추출과 복원 성능의 완료를 구분합니다.**

1. **로컬 캡션 검증:** Qwen3.5 문맥 조건의 잔여·새 오류를 확인하고, 키프레임·수신 자료·생성 잡음을 고정한 캡션 교체 복원 비교를 준비. 현재 근거는 캡션 AI 검토까지이며 기본 v2를 교체하지 않음. [결과](ETRI_COMBINED_REFERENCE_DIAGNOSIS.md#qwen-context)
2. **선택기 검증:** Qwen 30쌍 시간 측정을 전체 선택 완료로 확대 해석하지 않음. 순차 참조·필수 사건·최대 간격을 확인하고 기존 SKEM과 선택·전송량·복원 오류를 비교한 뒤 채택 판단. [시간 측정](ETRI_COMBINED_REFERENCE_DIAGNOSIS.md#qwen-selector-timing)
3. **중단 작업 관리:** 전체 원본의 순차 SKEM 보정은 체크포인트 보존 상태. 재개 시 TVSum 잔여 선택, WebVid 031 수정, 변경 구간 캡션 재검토·전체 검증 필요. [데이터 상태](DATA.md#full-extraction) · [재개](RUN_GUIDE.md#local-extraction)
4. **수신단 오류:** TVSum 40·54.5초 없는 얼굴과 보행 7.1~7.7초 위치 오류를 같은 수신 자료·잡음에서 참조·조건별로 분리. 첫 구간 모자이크의 시간표 오류 수정은 완료했고, 중간 객체 왜곡은 미해결. [근거](ETRI_COMBINED_REFERENCE_DIAGNOSIS.md#fc-lgvsc-four)

과거 8비트 SKEM·설명 간략화·후보 축소, AI 직접 선택과 v1 결과는 [보류 실험](ETRI_COMBINED_REFERENCE_DIAGNOSIS.md#selector-speed)으로 보존합니다. Qwen3-VL 자동 전처리, Qwen3.5 캡션, Qwen 선택 시간 측정은 서로 다른 실험이며 기존 FC-LGVSC의 완전 자동 대체를 뜻하지 않습니다.

## 다음 순서

1. **60초 후속 개선 비교:** 원본·기본 v2·후속 수정안, 남은 오류와 새 오류 확인.
2. **중·고전환 확대:** 장면 경계 오류·깜빡임·실행 실패 확인.
3. **장면전환 대응:** 검출·패킷 갱신·검출 누락 시 대안 비교.
4. **최종 평가:** 개발·교정 후 설정을 고정하고 미사용 영상에서 검증.

- 병행 작업: 목표 오류에 맞는 새 지표 1~2개 개발, 모듈별 학습 이력 정리.
- 동적 정보: 객체의 속도·방향·등장·퇴장이 설명에 빠지는지 확인.

<a id="evaluation"></a>
## 공통 평가 기준

- **채널:** AWGN 10 dB를 주 조건으로 사용.
- **공정 비교:** 입력·채널·공통 생성 조건 고정; 수신단 변경은 수신 데이터·초기 잡음 재사용.
- **영상:** 실제 연속 60초 이상, 장면전환 저·중·고; 반복·이어붙이기·감속 제외.
- **전체 실행:** 구간 간 상태를 유지해 평가; 짧게 재시작한 창은 별도 진단으로 표시.
- **오류:** 추가·누락·왜곡의 시각·영역·지속시간 기록; 정상 가림·퇴장과 구분.
- **정답:** 독립 검수자 2명, 방법 이름을 가린 비교, 불일치 조정; AI 표본은 탐색 자료.
- **보류 처리:** 관찰 불가·빈 주석은 오류 0으로 처리하지 않음.
- **검출 성능:** 오탐·미탐·관측률; 완화 성능은 남은 오류·새 오류로 별도 평가.
- **화질:** 평균 점수와 실패 구간을 함께 확인; PSNR·LPIPS 개선만으로 완화 성공 판정 금지.
- **전송 비용:** 키프레임·설명·부호화·갱신 비용 합산; MP4 용량과 구분.
- **정보 범위:** 수신 정보·설치 모델만 사용; 원본·수동 정답 사용 실험은 원인 진단으로 표시.
- **학습:** 사전학습과 로컬 추가 학습 구분; 정보 보강·재학습의 효과를 각각 확인.
- **최종 보고:** 독립 원본 기준으로 유형별 결과·불확실성·실패·시간·메모리 함께 보고.
- **판정 분리:** 실행 완료 · 오류 검수 · 완화 효과 · 지표 유효성 · 전송량 절감.

<a id="metrics"></a>
## 새 지표 개발

- 순서: 실제 오류 확인 → 목표 1~2개 선정 → 지표·모델 개발 → 독립 검증.
- 유효성: 오류 검출, 정상 변화 오경보, 관측 부족, 점수 포화 검사.
- 신규성: 기존 지표가 놓친 무엇을 측정하는지 근거 제시.
- 현재 판정: FSO·UEP·EOI 모두 최종 채택 보류; [지표 결과](METRICS.md) 참고.

<a id="candidates"></a>
## 후속 후보 — 효과 검증 전

- 키프레임 갱신: 긴 간격·장면 변화 때 기준 프레임을 추가하는 방법.
- 동적 캡션: 객체의 움직임·사건·발생 시각을 설명에 보강하는 방법.
- 경량 선택기: 무거운 SKEM의 선택을 작은 모델로 학습하는 방법; 구현·학습 미완료.
- 관측 보강·가속·미세조정: 품질·새 오류·전송량·전체 시간 확인 후 판단.
