# 개발 계획과 평가 기준

갱신: **2026-09-28**. [현황·E1~E4](README.md) · [ETRI 메일](ETRI_FOLLOWUP_EMAIL_SUMMARY.md)

## 개발 목표

**E1 시간축 신뢰성 · E2 할루시네이션 검출·완화 · E3 평가 신뢰성 · E4 전송량 절감**을 유지한다.
현재 우선순위는 AWGN에서 실제 생성 오류를 줄이고, 연속 60초 이상·장면전환 3유형에서 효과와 실패를 확인하는 것이다.
새 지표 1~2개를 모델과 함께 개발하되 지표 최종 채택을 기다리느라 완화 실험을 미루지 않는다.

## 지금 할 실험

**수신 키프레임의 잠재표현이 VAE 시간축의 어느 위치에 복원되는지 확인한다.**
결합안에서 악화된 사람 구간(원본 프레임 234→260)을 우선 대상으로 한다.

1. 한 프레임 조건을 17프레임 블록과 마지막 짧은 블록의 각 위치에 넣었을 때 실제 복원 위치를 확인한다.
2. 끝 키프레임·이전 참조 조건의 겹침과 덮어쓰기를 기록해 위치 반올림·참조 길이 효과를 분리한다.
3. 기존 수신 데이터·잡음·생성 설정을 유지하며 원본/기준선/변경안과 표적 중간 프레임을 비교한다.

산출물은 시간 위치 대응표, 재현 가능한 실패 사례, 수정 가설 하나의 대응 비교다.
**오류 감소와 새 왜곡 여부가 확인된 후보만 장시간으로 확장**한다. 현재 결합안의 일괄 적용은 보류다.
[최근 실험 근거](ETRI_COMBINED_REFERENCE_DIAGNOSIS.md#decoder)

## 다음 순서

| 순서 | 작업 | 연결 목표 | 완료 근거 |
|---|---|---|---|
| 1 | 같은 60초 영상의 전체 기준선/완화 비교 | E1·E2·E4 | 누적 상태를 유지한 세 영상, 잔존·새 오류, 비용·시간·메모리 |
| 2 | 중·고전환 개발 영상으로 확장 | E1·E2 | 유형별 실제 처리 길이, drift·깜빡임, 장면 경계 오류·실행 실패 |
| 3 | 씬 검출·키프레임/패킷 갱신·누락 대안 비교 | E1·E2·E4 | 경계·갱신·초기화 로그, 누락 시 효과·부작용·비용 |
| 4 | 개발·교정 후 방법을 고정해 미사용 영상 평가 | E1~E4 | 독립 정답, 유형별 대응 결과·불확실성, 성공·실패·새 왜곡 |

함께 준비할 것은 실제 목표 오류 1~2개와 지표, 모듈별 학습 근거, 객체별 속도·방향·등장/퇴장 정보의 누락 분석이다.
수신단 추가 전송량이 0이라는 사실만으로 E4의 절감 효과를 입증하지 않는다.

## 공통 평가·보고 기준

| 이메일 요청 | 실험에서 확인할 근거 |
|---|---|
| AWGN 중심 검출·완화 | 동일 입력·채널·공통 생성 조건과 전송 비용 |
| 원본/완화 전/완화 후 | 동기 영상, 오류 시각·영역·Added/Missing/Distorted, 성공·미완화·새 왜곡 |
| 연속 60초 이상·장면전환 저/중/고 | 원본 출처·시간축·유형, 실제 출력 길이·시간·메모리·실패 |
| drift·깜빡임·씬 체인지·누락 대안 | 키프레임 이후 시간별 오류, 경계·패킷 갱신·이전 참조 초기화 로그 |
| 학습·동적 정보 충분성 | 모듈별 학습 자료·체크포인트, 정보 보강 비교와 재학습 필요성 |

5분은 비교 사례다. 영상 수·SNR·시드·합격 수치는 평가 전에 프로젝트가 정하며 메일의 확정 지시와 구분한다.
채널 종류별 비교·Rayleigh/SDR·안전 중요 응용 인증은 현재 완료 조건에 포함하지 않는다.

**조건·비용:** 주 조건은 AWGN 10 dB다. 입력 해시·시간축·해상도·공통 생성 설정·평가 코드를 맞춘다.
수신단만 바꾸면 동일 패킷과 가능한 범위의 초기 잡음·난수 상태를 재사용한다. 같은 시드만으로 같은 잡음을 보장하지 않는다.
추가 키프레임·설명은 공통 패킷의 잡음을 대응시키고 추가 비용을 기록한다. 같은 예산 상한과 같은 실제 사용량은 구분한다.
수신단은 받은 정보와 설치된 모델만 사용한다. 원본·수동 정답을 넣는 조건은 원인 진단으로 표시한다.
시각 심벌·메타데이터·rate index·부호화·패딩·갱신·사용한 재전송을 합산하고 제외한 물리 계층 비용을 밝힌다.
MP4나 복소수 저장 파일 크기를 무선 전송 비트로 해석하지 않는다.

**입력·시간축:** 원본 한 영상의 실제 연속 구간을 쓰며 반복·무관한 클립 연결·감속으로 길이를 늘리지 않는다.
shot 편집 경계와 의미적 scene 변화를 구분한다. 자동 경계 후보는 정답이 아니다.
내부 구간 처리의 참조·상태 전달, 경계 중복·누락, scene 초기화 정책을 검사한다.
짧게 재시작한 창은 60초 전체 누적 상태 검증이 아니다. 실패도 실행 성공률의 분모에 남긴다.
[입력·분할](DATA.md) · [실행법](RUN_GUIDE.md#long-video)

**오류 정답:** Added는 없는 내용 추가, Missing은 존재해야 할 내용 누락, Distorted는 형태·속성·동작·관계 왜곡이다.
정상 가림·퇴장·원본 편집·마술을 생성 오류로 오인하지 않는다. drift·깜빡임·사건 순서·이전 장면 잔류는 추가 태그다.
시각/프레임·객체·가능한 영역·지속시간·심각도·확실성·근거 이미지를 남긴다. Missing은 원본 영역과 좌표 기준을 쓸 수 있다.
점수 계산에 쓴 검출기·VLM 출력을 정답으로 재사용하지 않는다. AI 단독·비맹검 표본은 탐색 근거이며 전 구간 발생률이 아니다.
정식 검수는 독립된 두 검수자, 방법 이름을 가린 복원 비교, 불일치 조정을 기준으로 한다.
오류 0도 전 구간 확인을 명시한다. 빈 주석·관측 불가·정답 부족은 보류하며 0으로 채우지 않는다.

**검출·완화:** 검출은 오탐·미탐·관측률, 완화는 잔존·새 오류와 지속시간을 각각 평가한다.
평균 화질이 짧은 실패를 가리지 않게 표적 중간 프레임도 확인한다. PSNR·LPIPS 개선은 할루시네이션 감소와 별개다.
키프레임 선택 성공은 씬 검출 성공이 아니다. 실제 누락과 통제한 누락/지연에서 대체안 유무·새 오류·갱신 비용을 비교한다.
최대 간격·주기 갱신·재검사·수신 프레임 기반 출력은 검증 대상 후보이며 효과가 확정된 기능이 아니다.

**학습:** NTSCC 이미지 코덱, 의미 추출기, Open-Sora 영상 생성기의 사전학습과 로컬 추가 학습을 구분한다.
조건 누락·반영 실패·시간축 표현 문제를 분리한 뒤 무학습 보강과 동영상 미세조정 필요성을 판단한다.
[현재 구조·학습 확인 항목](MODEL_ARCHITECTURE.md)

**최종 보고:** 방법·문턱·허용 손실·지표·비교 조건을 평가 전에 고정한다. 원본/관련 콘텐츠 그룹 단위의 대응 차이·신뢰구간을
유형·데이터셋별로 보고한다. 프레임·시드·같은 원본의 120초 확장을 독립 원본 수로 세지 않는다.
동기 비교영상, 오류·갱신 기록, 해시·비용·시간·메모리와 성공·실패·새 왜곡·보류를 모두 남긴다.
**실행, 주석, 완화 효과, 길이·유형 충족, 지표 유효성·신규성, 전송량 절감은 각각 판정**한다.

## E3 지표 개발 원칙

실제 복원 오류 확인 → 목표 1~2개 선정 → 모델·지표 공동 개발 → 독립 검증 순으로 진행한다.
관련 기존 지표가 놓치는 오류·개선을 무엇으로 설명하는지 보이며, 모든 기준선에 모든 조건에서 우세할 필요는 없다.

| 판단 | 필요한 근거 |
|---|---|
| 지표 유효성 | 독립 정답·오류 강도 반응·정상 외형 변화 오경보·관측률·포화·개선과 퇴화 반영 |
| 모델 개선 | 같은 조건의 실제 오류 감소와 새 오류·비용·다른 품질 변화 |
| 신규성 | 기존 수식·입력·측정 대상과 차이, 구성 요소 효과·추가 정보 |

모델이 더 정확하면 더 좋은 점수를 받아야 한다. 점수 상승·이름 변경·임의 가중합만으로 유효성이나 신규성을 주장하지 않는다.
오류량 지표의 방향, 화면/세계 좌표, 선택/전체 객체, 원본 대비 오류/수신 근거 부족을 구분한다.
지표를 학습·설정 선택·생성 제어에 썼다면 독립 자료로 개선을 재확인한다.
수신 근거 지표는 원본·복원을 고정한 근거 변경/제거 검사도 포함한다.
현재 FSO·EOI·UEP의 판정과 과거 실패는 [지표 연구 기록](METRICS.md)에서 관리한다.

## 후속 후보와 조사 이력

| 후보 | 착수 전에 필요한 근거 |
|---|---|
| 최대 키프레임 간격·씬별 갱신 | 추가 전송·캡션 갱신·scene 초기화를 분리하고 실제 오류와 비용 비교 |
| 동적 캡션·사건 정보 보강 | 객체·방향·속도·시각 누락 사례와 수신단 조건 반영 확인 |
| 학습형 키프레임 선택기 | 고정 경량 인코더 + 최근 선택 프레임 특징 + 작은 MLP/GRU로 SKEM 모방; 구현·학습 미완료 |
| 저해상도 관측 보강·생성 가속·미세조정 | 흐림·새 오류·전체 처리 비용과 실제 수신 근거 검증 |

선택기 교사 자료는 선택/생략 후보와 PSSS 점수를 포함하고 원본별로 분할한다. TVSum 요약 중요도를 복원 정답으로 쓰지 않는다.
학생의 순차 선택과 실제 LGVSC 복원·전송량·전체 시간을 평가한다. 교사 일치율만으로 품질 보존을 주장하지 않는다.
새 대형 모델·재학습은 현재 원인 진단을 대신하지 않는다.
