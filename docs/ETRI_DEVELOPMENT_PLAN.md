# ETRI 연구 개발 계획

- 작성일: 2026-09-11
- 개발 방향 개정일: 2026-09-16
- 상태: 지표 후보의 통제 실험과 후속 재평가를 완료했다. 최종 지표 유효성·신규성과
  개선 모델의 성능 우위는 아직 입증하지 않았다.
- 연구 기반: [현재 모델 구조](MODEL_ARCHITECTURE.md)의 LGVSC SKEM+DSA 경로
- 기준선: [공식 실행 설정](../configs/etri_official.json)과 [실행·검증 기록](ETRI_OFFICIAL_PROTOCOL.md)

새 지표 개발의 목적은 **우리 모델이 개선하려는 의미적 품질을 측정하고, 실제 개선됐을 때
기존 모델보다 좋은 평가를 주는 지표 1~2개를 만드는 것**이다. 모델의 개선 대상 선정과
지표 개발을 함께 진행한다. 같은 특성을 기존 모델이 더 잘 보존하면 기존 모델에도 더 좋은
평가를 줘야 한다. 현재 적용할 세부 기준은 [새 지표 개발 지침](METRIC_DEVELOPMENT_STRATEGY.md)에 정리한다.
이는 기존 ETRI 목표에 대한 이 프로젝트의 개발 방향을 구체화한 것이며, 새로운 공식 요구사항을 뜻하지 않는다.

## 1. 확정한 ETRI 목표 네 가지

| ID | 연구 목표 | 핵심 산출물 |
|---|---|---|
| E1 | 시간축·영상 신뢰성 확보 | 동작·방향·궤적·사건 순서를 보존하는 영상 복원 구조와 검증 결과 |
| E2 | 생성 복원의 할루시네이션 검출·억제 | 객체 추가·누락·왜곡을 검출하고 줄이는 방법과 효과 검증 |
| E3 | 의미 전달 평가 체계의 신뢰도 확보 | **시맨틱 영상 전송을 위한 새로운 평가 지표 1~2개의 정의·수식·구현·유효성 검증** |
| E4 | 의미 신뢰성을 유지하면서 전송량 절감 | 의미 정확도와 총 전송량의 관계 및 개선 결과 |

E3의 주된 연구 성과는 E1·E2·E4의 실제 개선을 평가할 수 있는 새로운 지표다.
특정 의미 오류에 특화된 지표여도 되며, 모든 기존 지표보다 모든 조건에서 우수할 필요는 없다.
목표 오류와 그 감소를 정확히 측정하고, 관련 기존 지표와 비교해 제공하는 추가 정보를 입증한다.
정답 주석, 공통 평가기, 비교 보고서는 이를 위한 지원 산출물이다. 지표의 유효성,
개선 모델의 우수성, 지표의 학술적 신규성은 각각 검증한다. 기존 지표의 이름을 바꾸거나
가중치를 임의로 합치는 것만으로 신규성을 주장하지 않는다.
SAVER 등의 개별 모델 아이디어는 구현 방법의 후보이며 ETRI 목표 자체에 포함하지 않는다.

## 2. LGVSC 한계와 연구 목표의 연결

논문의 한계와 이를 ETRI 연구에 적용한 해석을 구분한다.

| ID | 논문이 밝힌 한계 | 관련 부분 | 이 계획의 대응 |
|---|---|---|---|
| L1 | 실시간 처리에 큰 계산 비용과 지연이 필요 | 송신단 SKEM/InternVL, 수신단 Open-Sora | 5단계 처리 속도 개선 |
| L2 | 생성 디코더에 픽셀 수준 충실도 보존을 위한 명시적 제약이 없음 | 생성 복원과 그 조건 정보 | 2·3단계 정밀 복원 개선, 1단계 새 지표로 오류 측정 |
| L3 | 이동성을 포함한 Rayleigh 페이딩과 실제 SDR 평가가 향후 과제 | 채널 경로와 전체 시스템 검증 | 6단계 독립·실환경 검증 |
| L4 | 자율주행·의료 영상 같은 안전 중요 용도는 추가 연구 필요 | 응용 분야별 데이터·실패 기준·검증 | 별도 응용 검증 범위로 관리 |

E1·E2의 동작 오류와 할루시네이션은 L2와 관련되는 연구 방향이다. 논문이 보행 방향
오류나 특정 객체 환각을 각각 직접 보고했다는 뜻은 아니다. E3는 L4의 신뢰성 입증과
간접적으로 연결된다. E4는 LGVSC도 추구하는 공통 목표이며 위 네 한계에 일대일로
대응하지 않는다. 시간축의 의미 정확도(E1)와 처리 지연(L1)은 별도로 평가한다.

근거: [LGVSC 논문](https://arxiv.org/html/2606.12899v1)의 §III-D, §III-E, 결론 및
작업공간 `reference/paper/LGVSC: A Large-Model-Driven Generative Video Semantic Communication Framework/main.tex`의
`Channel Robustness Analysis` 부록. 모듈별 처리 방식과 공개 코드의 차이는
[공식 실행 기록](ETRI_OFFICIAL_PROTOCOL.md)에 정리돼 있다.

## 3. 진행 순서와 현재 출발점

**기존 모델의 실제 오류 확인 → 개선할 의미적 특성 선정 → 모델과 지표 개발
→ 독립 정답으로 지표의 유효성과 모델 개선 효과 검증**을 기본 흐름으로 삼는다.

아래 1~6단계는 작업 영역과 확장 순서를 나타낸다. 1단계 지표의 최종 채택을 기다리지 않고
선정한 오류에 맞춰 2·3단계 모델 개선을 함께 진행한다. 개발 과정의 반복 비교 뒤에는
지표와 모델을 고정하고 별도 미사용 자료로 평가한다. 이어 전송량·처리 속도를 최적화하고
독립·실환경 검증으로 주장 범위를 넓힌다.

현재 공식 실행 프로필로 첫 ETRI 영상의 송신·채널·복원·화질 평가를 완료한 근거가 있다.
2026-09-12에는 새 데이터의 짧은 9·17프레임 영상에서도 SKEM+DSA 전체 경로를 확인했고,
사람 검수 없는 2,432개 통제 사례에서 지표 후보 두 개를 평가했다. 두 후보는 채택 기준 미달이다.
2026-09-14에는 이전 원본·seed와 분리한 1,176개 사례에서 MTE·OTF를 추가 평가했지만
채택 기준과 전체 비교 지표에 대한 우위를 함께 충족하지 못했다.
이는 당시 통제 실험의 판정이며, 전체 기존 지표에 대한 우위를 앞으로의 모든 후보에 요구한다는
뜻은 아니다. 2026-09-16 후속 결과에서도 자연 영상 오경보·점수 포화·관측 부족이 남았다.
기존 실행과 후보 실험은 신규 지표의 최종 유효성이나 개선 모델의 우위를 입증하지 않는다.
첫 공식 실행의 완료 근거는
[첫 영상 검증 기록](validation/2026-09-11-etri01-official-full.json)을 사용한다.

기존 실행 프로필과 결과는 기준선으로 보존한다. 신규 지표와 모델 변경은 별도 버전·설정으로
비교하며, 지표 구현 변경의 효과와 복원 모델 변경의 효과를 분리해 보고한다.

## 4. 단계별 개발 내용

### 1단계 — 새로운 평가 지표 1~2개 개발

**대응: E3. E1·E2·E4에서 목표로 삼은 모델 개선을 측정하고 입증할 평가 수단을 만든다.**

1. 기존 LGVSC·SGD-JSCC와 현행 모델의 실제 복원에서 의미 오류를 확인한다. 점수 추출기와
   독립된 근거로 오류가 확인된 구간과 미확정 진단 구간을 구분하고, 관련 기존 지표의 반응을 분석한다.
2. 개선할 특성 1~2개와 모델 변경 가설을 먼저 정한다. 예를 들어 소멸한 객체의 잔존 오류를
   줄이려 한다면, 모델의 어떤 조건 정보·복원 구조를 바꾸고 어떤 오류 감소를 측정할지 함께 정한다.
   FSO·UEP·EOI는 이 연결에 따라 선택·수정할 후보이며, 기존 통제 실험 통과만으로 확정하지 않는다.
3. 선행 지표와 비교해 측정 대상·차별성을 정하고 수식과 코드를 개발한다. 입력, 평가 단위,
   객체 대응, 물리적 시간축, 점수 방향·범위, 정규화, 가려짐·관측 불가 처리를 명시한다.
   비교하는 모든 모델에 같은 평가 규칙을 적용한다.
4. 지표 자체의 유효성을 검증한다. 코드가 정답을 기록한 통제 오류와 정상 외형 변화 사례에서
   오류 강도 반응, 오탐·미탐·관측률, 핵심 구성의 효과를 확인하고 관련 기존 지표와 비교한다.
   모든 화질 지표를 모든 조건에서 이기는 것을 일괄 완료 조건으로 두지 않는다.
5. 선정한 2·3단계 모델 변경과 함께 개발 비교를 진행한다. 최종 비교 전에는 지표·교정값·모델·
   비교 조건을 고정하고, 별도 미사용 자연 영상의 실제 복원에서 독립 정답으로 확인한 개선·퇴화가
   새 지표의 변화와 일치하는지 검증한다. 기존 모델이 더 잘한 사례에도 같은 규칙을 적용한다.
6. 사람의 추가 검수 없이 진행할 때에도 점수 추출기 출력을 정답으로 재사용하지 않는다.
   통제 편집의 정답과 실제 생성 복원의 독립 정답을 구분하고, 정답이 부족하면 그 범위는 진단으로
   남긴다. AI 시각 검토는 근거·불확실성을 기록하며 사람 판정과의 일치도를 주장하지 않는다.

- 산출물: 목표 오류–모델 변경–지표의 연결 근거, 지표 정의·수식·코드, 독립 정답과 검증 자료,
  관련 기존 지표 비교, 기존·개선 모델의 대응 비교 결과.
- 지표 완료 판단: 사전에 정한 적용 범위에서 오류와 오류 변화량을 신뢰성 있게 측정하고,
  관련 기존 지표와의 차별성·신규성을 별도 근거로 설명한다. 최종 유효성은 미사용 자료에서 확인한다.
- 모델 우위 판단: 독립 정답과 유효성이 확인된 지표에서 실제 개선을 확인하고 전송량·지연·다른 품질의
  변화를 함께 보고한다. 모델 우위가 확인되지 않아도 유효한 지표일 수 있으며, 두 판정을 합치지 않는다.

### 2단계 — 시간축 복원 구조 개선

**대응: E1, L2.**

- 선정한 시간축 오류에 대해 1단계와 함께 개발하고, 각 변경이 줄이려는 오류와 대응 지표를 명시한다.
- 송신단에서 방향·위치·궤적·포즈·동작 순서 중 필요한 정보를 추출하고 표현한다.
- 키프레임 선택과 보조정보가 회전·등장·소멸 같은 사건을 얼마나 담는지 분석한다.
- 전달한 정보를 생성기의 공간·시간 조건에 연결한다. DSA의 길이·조건 정렬과
  실제 동작을 지정하는 조건 주입을 구분해 실험한다.
- 추가 정보의 전송 비용을 처음부터 기록하고, 보조정보 종류와 주입 방식별로 비교한다.

- 산출물: 시간축 정보 표현, 송수신 계약, 생성 조건 주입 코드, 모듈별 비교 결과.
- 완료 판단: 새 지표와 독립 정답에서 방향·궤적·사건 순서의 개선을 확인하고,
  전송량 증가와 다른 품질 항목의 손실을 함께 설명한다.

### 3단계 — 할루시네이션 제어

**대응: E2, L2.**

- 선정한 할루시네이션 오류에 대해 1단계와 함께 개발하고, 제어 효과를 확인할 독립 정답을 준비한다.
- 수신한 의미 정보와 생성 결과를 비교해 객체 추가·누락·속성·관계 왜곡을 검출한다.
- 오류 종류에 따라 생성 조건 수정, 생성기 내부 조건 주입, 제한된 구간 재생성을 연결한다.
  프롬프트·실행 설정 변경만의 효과와 생성기 구조 변경의 효과를 분리한다.
- 원본 영상은 최종 평가에 사용한다. 수신단 제어는 실제로 수신한 정보와 설치된 모델만
  사용하며, 송신 과정에서 이미 빠진 정보의 검출 한계를 별도로 보고한다.
- 원래 존재하는 객체를 잘못 억제하는 오류와 재생성 비용도 함께 평가한다.

- 산출물: 의미 검증·생성 제어 경로, 오류 유형별 실험, 제어 전후 비교 결과.
- 완료 판단: 제어에 사용하지 않은 정답/평가에서 오류 감소를 입증하고, 잘못된 억제와
  재시도 비용이 사전에 정한 허용 범위를 만족하는지 확인한다.

### 4단계 — 전송량 최적화

**대응: E4.**

- 키프레임 수·구간 길이, 보조정보의 종류·밀도, 양자화·전송 보호 수준을 조절한다.
- 같은 의미 정확도에서 필요한 전송량과 같은 전송 예산에서 얻는 정확도를 모두 비교한다.
- 메타데이터, 채널 부호, 사용한 피드백·재전송까지 포함해 비용을 기록한다.
  연속 JSCC 심벌의 파일 저장 바이트, 디지털 패킷 바이트, 실제 복소 채널 사용 횟수를
  구분한다. 미구현 물리 계층 비용은 포함 범위 밖으로 명시한다.

- 산출물: 전송 정책, 완전한 항목별 계측, 전송량–의미 정확도 곡선.
- 완료 판단: 의미 정확도 허용 손실을 미리 정한 뒤 총 전송량 감소를 검증한다.

### 5단계 — 처리 속도 개선

**대응: L1.**

- 단계별 프로파일링으로 의미 추출, 전송 처리, 모델 로딩, 생성 시간을 분리한다.
- SKEM의 비교 후보 선별·중복 연산 제거·캐시와 Open-Sora의 생성 단계 축소·경량화를
  각각 실험한다. 가속 때문에 놓친 의미 변화도 새 지표로 확인한다.
- GPU·정밀도·해상도·생성 길이와 측정 시작/종료 지점을 맞춰 비교한다.
  초기 로딩을 포함한 지연과 모델이 준비된 상태의 지연을 별도로 기록한다.

- 산출물: 지연 분석, 가속 설정/구현, 정확도–전송량–지연 비교 결과.
- 완료 판단: 의미 정확도 기준을 유지하며 지연을 줄인다. 실제 측정이 해당 입력 영상의
  처리 속도 요구를 충족할 때만 그 조건에서의 실시간 동작을 주장한다.

### 6단계 — 독립·실환경 검증

**대응: L3. E1~E4의 최종 유효성도 확인한다.**

- 개발에 사용한 ETRI 10개 영상과 별도로 미사용 평가 영상을 준비한다.
- 지표·모델·임계값·비교 조건을 고정하고, 영상/사건 단위의 대응 비교와 신뢰구간을 보고한다.
- AWGN 기준선에서 시작해 Rayleigh 페이딩, 이동에 따른 채널 변화, 패킷 손실로 확장한다.
  이후 실제 SDR 송수신과 실제 채널 추정·복호 결과까지 포함해 평가한다.
- 잡음 모델 실험, 실제 장비 송수신, 분야별 응용 검증을 서로 다른 근거로 기록한다.

- 산출물: 독립 데이터 평가, 채널 조건별 실험, SDR 검증 기록, 최종 재현 자료.
- 완료 판단: 동결된 조건에서 개선 효과가 재현되는 범위와 실패 조건을 확인한다.

## 5. 모든 단계의 공통 비교 원칙

- 개선할 의미적 특성, 관련 기준선, 허용 손실과 평가 범위를 결과를 보기 전에 정한다.
  특정 오류에 대한 개선과 전체 영상 품질의 우위를 구분한다. 기존 모델이 목표 특성을 더 잘 보존하면
  그 모델에도 더 좋은 평가를 주며, 우리 모델의 우위를 만들기 위한 사후 가중치·문턱·평가 집합 선택을 하지 않는다.
- 같은 입력 영상·채널 조건·평가 코드로 비교하고, 전송 예산과 복원 계산 비용을 맞추거나 비용–품질 곡선으로
  보고한다. RX 근거를 쓰는 지표는 각 모델이 실제 수신한 정보를 같은 해석 규칙으로 평가한다.
  지표끼리의 구성 비교에서는 사용할 수 있는 입력 정보의 차이도 분리해 확인한다.
- 원본 시간축, 프레임 중복·누락, 해상도 변환을 명시한다. 평가 정렬로 실제 동작 지연이나
  사건 순서 오류를 숨기지 않는다.
- 새 지표와 기존 지표, 총 전송량, 단계별/전체 처리 시간, 실패율을 함께 보고한다.
  한 가지 합성 점수만으로 전체 성능 우위를 결론 내리지 않는다.
- 새 지표를 학습·선택·재생성 제어에 사용했다면 그 점수 상승만으로 유효성을 주장하지
  않는다. 독립 정답과 별도 평가로 확인한다.
- 원본에 대한 자동 검출기의 오탐·미탐과 자동 정답 자료의 적용 범위·불확실성도 기록한다.
  관측 불가와 정답 부족을 정상 점수 0으로 바꾸지 않으며, 보류율과 적용 가능한 범위를 함께 보고한다.
- 프레임들을 독립 표본으로 간주하지 않고 영상/사건 단위로 통계를 계산한다.
  반복 시드는 실제 생성 결과에 반영되는지 확인하고 독립 반복 수를 부풀리지 않는다.
- 지표 이름·수식·임계값·허용 손실·데이터 분할·모델/코드 버전을 최종 평가 전에 고정한다.
  개발 비교에 사용한 자료는 최종 독립 평가에 재사용하지 않는다. 개선이 확인되지 않은 변경도
  결과로 남기고 다음 구조 수정의 근거로 사용한다. 과거 사전 등록 기준과 결과는 그대로 보존한다.

## 6. 안전 중요 용도의 별도 검증 범위

자율주행·의료 영상의 적합성(L4)은 ETRI 일반 영상 평가나 SDR 실험만으로 입증하지 않는다.
해당 분야의 데이터, 중요한 사건, 허용 실패 기준을 별도로 정의하고 검증한다.
이 계획에서 주장할 수 있는 범위는 실제로 평가한 분야와 조건으로 제한한다.

## 7. 다음 개발 작업

1. 기존 실제 복원과 독립 검토에서 확인된 오류를 정리하고, **모델에서 개선할 특성 1~2개**를 선정한다.
   아직 불확실한 객체·사건은 확정 오류와 구분한다. 이미 분석한 영상은 개발 자료로 사용한다.
2. 각 특성에 대해 모델 변경 가설, 후보 지표, 독립 정답, 관련 기존 지표를 한 묶음으로 정의한다.
   FSO·UEP·EOI를 유지할지는 목표 오류와 측정 신뢰성에 따라 판단한다.
3. 모델 변경과 평가기 개선을 함께 진행한다. FSO의 관측 부족, UEP의 자연 영상 오경보·포화 등
   [현재 확인된 문제](METRIC_REVISION_RESULTS.md)를 해결하고 개발 자료에서 대응 비교한다.
4. 지표·모델·평가 조건을 고정한 뒤 새 자연 영상의 실제 복원을 독립 정답으로 평가한다.
   지표의 유효성, 모델의 개선 효과, 지표의 신규성을 구분해 보고한다.

평가 도구 구축이나 통제 실험 통과만으로 E3 완료를 선언하지 않는다. 모델 개발을 진행하면서
그 개선 효과를 신뢰성 있게 드러낼 지표를 개발·검증하는 것을 현재의 연구 방향으로 삼는다.
