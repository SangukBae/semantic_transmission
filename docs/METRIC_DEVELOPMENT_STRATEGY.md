# E3: 새 지표 개발 지침

갱신: **2026-09-28**. [과제 목표](README.md) · [개발 계획](ETRI_DEVELOPMENT_PLAN.md) ·
[공통 평가 기준](ETRI_FOLLOWUP_PROTOCOL.md)

## 목적

**모델이 개선하려는 의미 오류와 그 감소를 신뢰할 수 있게 측정하는 새 지표 1~2개를 만든다.**
E1 시간축 신뢰성·E2 할루시네이션 완화·E4 전송량 절감의 효과를 평가하는 기존 E3 목표다.
지표의 최종 채택을 기다리느라 장시간 복원·완화 개발을 미루지 않는다.

객체 소멸 후 잔존, 잘못된 움직임 지속, 사건 순서, 근거 없는 객체 추가 등에서
실제 복원 오류와 수정 가능성을 확인한 뒤 목표를 고른다. 모든 종류의 품질을 한 점수로 설명할 필요는 없다.
기존 모델이 목표를 더 잘 보존하면 그 모델에도 더 좋은 평가를 줘야 한다.

## 따로 입증할 세 가지

| 판단 | 필요한 근거 |
|---|---|
| 지표 유효성 | 독립 정답과의 일치, 오류 강도 반응, 정상 외형 변화의 오경보, 관측률·포화, 실제 복원 개선·퇴화 반영 |
| 모델 개선 효과 | 같은 조건의 기준선/변경안에서 실제 오류 감소, 새 오류·비용·다른 품질 변화 |
| 지표 신규성 | 선행 지표의 수식·입력·대상과 차이, 구성 요소 효과, 관련 기준선 대비 추가 정보 |

새 점수의 상승만으로 세 판단을 모두 통과하지 않는다. 이름 변경이나 임의 가중합만으로 신규성을 주장하지 않는다.
오류량처럼 낮을수록 좋은 지표는 방향을 명시한다.

## 개발 순서

1. **실제 오류 확인:** 원본·수신 자료·복원·설정을 보존하고 확실한 오류와 불확실한 관찰을 나눈다.
2. **목표 선정:** 오류 1~2개마다 모델 변경 지점·예상 효과·부작용과 측정 대상을 연결한다.
3. **공동 개발:** 원본별로 분리한 개발·교정 자료에서 모델과 지표를 개발하고 각각의 변경 효과를 분리한다.
4. **측정법 검사:** 통제 오류·정상 외형 변화·구성 제거 비교와 실제 생성 복원에서 추출기 실패를 확인한다.
5. **평가 고정:** 수식·추출기·문턱·모델·자료·허용 오차·오탐/미탐/관측률·통계를 최종 평가 전에 고정한다.
6. **미사용 영상 검증:** 독립 정답과 오류 변화 방향·모델 순위·불확실성을 비교한다. 수정 시 새 개발 버전으로 관리한다.

## 핵심 판단 규칙

- 관련 기존 지표와 비교해 어떤 오류·개선을 추가로 설명하는지 보인다. 모든 기준선에 모든 조건에서 우세할 필요는 없다.
- 점수 계산에 쓴 검출기·VLM 출력을 정답으로 재사용하지 않는다. 합성 편집 정답과 실제 복원의 독립 근거를 구분한다.
  AI 검수의 표집 범위·독립성·불확실성도 명시한다.
- 화면 좌표와 세계 좌표, 선택 객체와 전체 객체, 원본 대비 오류와 수신 근거 부족을 구분한다.
- 수신 근거를 사용하는 지표는 같은 원본·복원에서 근거만 바꾸는 검사와 근거 제거 비교를 포함한다.
- 관측 불가·정답 부족을 0으로 채우지 않는다. 보류율·점수 포화·적용 범위를 함께 보고한다.
- 지표를 학습·설정 선택·재생성 제어에 사용했다면 독립 평가로 실제 개선을 확인한다.
- PSNR·LPIPS 등 화질과 Added/Missing/Distorted 정답은 별도 축이다. 단일 평균이 짧은 생성 실패를 가리지 않게 한다.
- 조건·비용 대응, 장시간 3유형, 독립 검수, 원본 단위 통계는 [공통 프로토콜](ETRI_FOLLOWUP_PROTOCOL.md)을 따른다.

## 기존 후보의 현재 위치

최신 지표 실행 근거는 [2026-09-16 v6 재평가](METRIC_REVISION_RESULTS.md)다. 모두 개발 후보이며 최종 채택은 보류다.

| 후보 | 측정 대상 | 남은 문제 |
|---|---|---|
| FSO: 금지 상태 점유량 | 잔존·조기 등장·잘못 지속되는 움직임/방향 | 통제 실험 일부 개선·악화, 자연 영상 관측 부족, 실제 복원 수치 정답 부족 |
| UEP: 근거 없는 존재 점유량 | 수신 근거로 뒷받침되지 않는 객체 | 정상 자연 영상 오경보 32/40, 실제 복원 12/12에서 1.0 포화 |
| EOI: 사건 순서 역전율 | 원본 사건 순서의 보존 | 실제 복원 12개 모두 대응률 부족으로 보류, 차별성·모델 변화 반영 검증 필요 |

세 후보를 모두 채택할 필요는 없다. 의미 객체와 배경/부분 영역의 구분, 지속적인 객체 대응,
관측·정답 문제를 먼저 해결하고 실제 오류 측정에 유효한 1~2개를 선정한다.
FSO 존재 성분과 `ghost_max`의 동일성은 [v5 결과](FSO_UEP_RESULTS.md)의 기존 판단을 유지한다.

## 기록의 적용 범위

[실험 목록](EXPERIMENT_INDEX.md)의 과거 프로토콜·결과·판정은 당시 조건으로 보존한다.
일부 문서는 실행 선언의 해시 검사 대상이므로 현재 현황을 쓰기 위해 덮어쓰지 않는다.
통제 실험 통과를 자연 영상 유효성·LGVSC 모델 우위·장시간 완화·논문 신규성으로 확대하지 않는다.
