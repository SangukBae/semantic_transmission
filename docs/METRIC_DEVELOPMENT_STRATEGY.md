# 새 지표 개발 지침

- 개정일: 2026-09-21
- 적용: 앞으로의 지표 설계·모델 개발·비교 실험
- 상위 계획: [ETRI 연구 개발 계획](ETRI_DEVELOPMENT_PLAN.md)
- 요구사항: [ETRI 후속 메일](ETRI_FOLLOWUP_EMAIL_SUMMARY.md), [후속 평가 프로토콜](ETRI_FOLLOWUP_PROTOCOL.md)
- 상태: 개발 방향을 정리한 문서다. 새 실험 수행이나 기존 후보의 최종 채택을 뜻하지 않는다.

## 1. 개발 목적

**우리 모델이 개선하려는 의미적 품질을 측정하고, 실제 개선됐을 때 기존 모델보다 좋은 평가를
주는 새로운 지표 1~2개를 만든다.** 이는 ETRI의 기존 E1·E2·E4 개선을 평가할 E3를 구체화한
프로젝트 개발 지침이며, 새로운 공식 ETRI 요구사항을 추가하는 것은 아니다.

2026-09-21부터 우선 적용 대상은 **AWGN에서의 할루시네이션 검출·완화와 장시간 영상의 시간축
신뢰성**이다. 새 지표는 이 효과와 부작용을 측정하는 수단으로 개발한다. 지표 신규성의 최종
입증을 완화 전후 영상 제공이나 60초 이상 확장 검토의 선행 조건으로 두지 않는다.

개선 대상은 객체 소멸 후 잔존, 동작·방향의 잘못된 지속, 사건 순서 오류, 근거 없는 객체 추가 등에서
실제 복원 오류와 모델 변경 가능성을 확인한 뒤 선택한다. 특정 문제에 특화된 지표여도 된다.
모든 기존 화질·시간축 지표보다 모든 조건에서 우수할 필요는 없다. 관련 기존 지표가 잘 드러내지
못하는 어떤 의미 오류와 개선을 추가로 측정하는지 근거를 제시한다.

비교하는 모든 모델에 같은 규칙을 적용한다. 기존 모델이 목표 특성을 더 잘 보존하면 기존 모델에도
더 좋은 평가를 줘야 한다. 우리 모델의 결과가 유리해지도록 최종 평가를 보고 수식·문턱·가중치나
평가 영상을 선택하지 않는다. 모델의 개선 효과가 없다는 결과도 연구 결과로 남긴다.

### 예시: 소멸한 객체가 복원 영상에 남는 오류

아래는 개발 방향을 설명하는 예시이며, 해당 모델 개선을 이미 구현·입증했다는 뜻은 아니다.

1. 기존 복원에서 객체가 사라져야 할 시점 이후에도 남는 구간을 독립 근거로 확인한다.
2. 소멸 정보를 전달하거나 복원 조건에 반영하는 모델 변경을 설계한다.
3. 잔존 정도·지속 시간을 측정할 지표를 정의하고 정상 가려짐·추출 실패를 구분한다.
4. 동일 조건의 기존·개선 모델에서 독립 정답상 잔존 오류가 감소하는지 확인한다.
5. 새 지표가 그 감소를 반영하는지, 관련 기존 지표와 비교해 무엇을 더 설명하는지 검증한다.
   오류를 줄이면서 정상 객체를 지우지는 않는지도 함께 평가한다.

## 2. 구분해서 입증할 세 가지

| 판단 | 확인할 질문 | 필요한 근거 |
|---|---|---|
| 지표의 유효성 | 목표 오류와 오류의 증가·감소를 정확히 측정하는가? | 점수 추출기와 독립된 정답, 오류 강도 반응, 오탐·미탐, 외형 변화 안정성, 관측률, 실제 복원에서의 변화 방향·순위 일치 |
| 모델의 개선 효과 | 개선 모델이 같은 조건에서 목표 오류를 실제로 줄였는가? | 기존·개선 모델의 대응 비교, 독립 정답과 유효한 지표, 전송량·지연·다른 품질의 변화 |
| 지표의 신규성 | 기존 정의·방법과 구별되는 연구 기여가 있는가? | 선행 지표의 수식·입력·측정 대상 비교, 핵심 구성의 효과, 관련 기존 지표 대비 추가 정보 |

모델이 새 지표에서 좋은 점수를 받는다는 사실만으로 지표의 유효성·신규성이 입증되지는 않는다.
반대로 개선 모델이 기준선보다 나쁜 경우에도 그 퇴화를 정확히 포착하는 지표는 유효할 수 있다.
오류량 지표에서는 값이 낮아지는 것이 개선이므로, 모든 결과에서 점수 방향을 명시한다.

## 3. 개발과 평가 순서

**기존 모델의 실제 오류 확인 → 개선할 특성 선정 → 모델과 지표 개발 → 독립 정답으로 개선 효과 검증**

1. **오류와 기준선 확인:** 기존 LGVSC·SGD-JSCC 및 현행 모델의 설정·출력을 보존한다.
   실제로 확인된 오류, 불확실한 구간, 관련 기존 지표의 반응을 구분한다.
2. **개선 가설 선정:** 목표 특성 1~2개마다 모델의 변경 지점, 예상 효과, 부작용, 측정할 지표를 연결한다.
   특정 후보 지표의 기존 통과 여부만으로 모델의 연구 대상을 정하지 않는다.
3. **모델·지표 개발:** 원본 단위로 분리한 개발·교정 자료에서 모델 변경과 지표 구현을 함께 진행한다.
   지표 변경 전후와 모델 변경 전후의 효과를 분리하고, 평가 입력·정답 범위를 맞춘다.
4. **지표 구성 검증:** 통제 오류, 정상 외형 변화, 핵심 구성 제거 비교로 오류 측정의 신뢰성을 확인한다.
   실제 생성 복원에서도 추출기 오류·점수 포화·관측 부족을 진단한다.
5. **최종 평가 고정:** 수식, 추출기, 교정값, 모델·설정, 비교 조건, 데이터 분할, 목표별 허용 오차와
   오탐·미탐·관측률 기준, 통계 방법을 결과 확인 전에 기록한다. 이미 분석한 자료는 개발 자료로 분류한다.
6. **미사용 자료 평가:** 새 자연 영상의 실제 복원에서 독립 정답과 비교한다. 실제 개선·퇴화와 지표 반응의
   일치, 모델 간 차이와 불확실성을 보고한다. 최종 평가 후 수정이 필요하면 새 개발 버전으로 관리한다.

장시간 비교에는 낮은/일반/높은 장면전환 빈도의 세 조건을 포함하고 실제 연속 구간 60초 이상을
목표로 실행 가능성을 검토한다. 이전 짧은 합성·WebVid 실험은 구성 검증과 개발 진단으로 유지하며,
그 결과를 긴 영상의 유효성으로 확대하지 않는다. 길이·유형·표본 수는 최종 평가 전에 기록한다.

지표의 최종 채택을 모두 마친 뒤에야 모델을 개발하는 순서는 요구하지 않는다.
최종 성능 주장은 동결한 지표·모델과 독립 평가 자료를 갖춘 뒤에 한다.

## 4. 비교 실험의 공통 기준

- **모델 간 조건:** 입력 영상·채널 조건·시간축·평가 코드를 맞춘다. 전송량과 복원 계산 비용을
  맞추거나 비용–품질 관계를 함께 보고한다. 다른 자원을 사용한 결과를 같은 예산의 우위로 해석하지 않는다.
- **지표 간 기준선:** 목표 오류와 관련된 기존 지표를 사전에 선정한다. PSNR·SSIM·LPIPS·CLIP 등은
  다른 품질 손실을 확인하는 데도 사용한다. 특정 과거 실험의 ‘기준선 전부에 우위’ 조건을 모든 새 후보의
  공통 요구로 확대하지 않는다. 우위를 주장하는 지표와 조건은 비교 근거를 제시한다.
- **독립 정답:** 통제 편집에서는 렌더러 상태·편집 기록 등을 사용할 수 있다. 실제 생성 복원에는 해당
  원본·복원과 결합된 별도 근거가 필요하다. 점수 계산에 쓴 검출기·VLM의 출력을 정답으로 재사용하지 않는다.
  사람의 추가 검수 없는 방식도 이 원칙을 지키며, AI 시각 검토의 범위와 불확실성을 명시한다.
- **수신 근거:** UEP처럼 RX를 쓰면 각 모델이 실제 수신한 근거에 같은 규칙을 적용한다.
  수신 정보에 따른 오류 판정이라는 범위를 명시한다. 구성의 효과를 볼 때는 원본·복원은 고정하고
  RX만 바꾸는 비교와 RX 제거·동일 입력 기준선 비교를 둔다. 영상 자체의 오류 감소도 독립 정답으로 확인한다.
- **목표와 부작용:** 목표 오류 감소와 정상 객체 삭제·다른 의미 오류 증가를 함께 평가한다.
  사건 누락·지연을 정렬로 숨기지 않는다. 화면 좌표와 세계 좌표, 선택 객체와 전체 객체의 정답 범위를 구분한다.
- **보류와 통계:** 정답 부족·관측 불가를 0으로 채우지 않는다. 보류율·점수 포화·적용 범위를 보고하고,
  같은 원본의 프레임·변형을 독립 영상 수로 세지 않는다. 원본 단위 대응 비교와 신뢰구간을 사용한다.
- **개발에 사용한 점수:** 지표를 학습·설정 선택·생성 제어에 쓰더라도 그 점수 개선만으로 성능을 입증하지
  않는다. 독립 정답과 별도 평가에서 실제 오류 감소를 확인한다.
- **ETRI 오류 보고:** Added·Missing·Distorted와 drift·깜빡임·동작·속도·사건 순서 태그를 연결한다.
  오류 프레임/시각·영역은 가능한 범위에서 독립 근거와 함께 기록한다. 원본 대비 오류와 RX 근거 부족을
  구분하며, UEP·FSO·EOI 점수를 곧바로 세 오류 유형의 정답으로 사용하지 않는다.
- **시간·장면별 분석:** 키프레임 이후 경과 시간별 오류와 씬 체인지 검출 누락/지연, 패킷 갱신·적용 지연을
  분리한다. 긴 정상 구간의 평균이 짧은 오류를 감추지 않도록 사건·유형별 지속량과 검출 성능도 보고한다.
- **전후 비교자료:** 동일 입력·AWGN 조건의 원본/완화 전/완화 후 영상과 성공·미완화·새 왜곡 사례를
  제시한다. 표시·사례 선정·보류 기록은 [후속 프로토콜](ETRI_FOLLOWUP_PROTOCOL.md)을 따른다.

## 5. 기존 후보의 위치와 다음 판단

아래는 2026-09-16 [v6 수정·재평가 결과](METRIC_REVISION_RESULTS.md)에 근거한 상태다.
현재 FSO·UEP·EOI는 개발·진단 후보이며, 최종 모델 성능 우위를 입증할 지표로 확정하지 않았다.

| 후보 | 연결 가능한 모델 개선 목표 | 현재 근거와 남은 문제 |
|---|---|---|
| FSO | 소멸 후 잔존, 조기 등장, 멈춤·방향 전환 후 잘못된 상태 지속 감소 | 일부 통제 실험 근거가 있다. v6에서는 성분별 개선·악화가 함께 있었고 자연 영상의 관측 부족, 실제 복원의 수치 정답 부족이 남았다. 목표 성분을 선택해 검증해야 한다. |
| UEP | 수신 근거로 뒷받침되지 않는 객체 추가 감소 | 통제 실험·RX 비교 근거가 있다. 정상 자연 영상 오경보 32/40과 실제 복원 12/12의 점수 1.0 포화가 남아 실제 모델 간 차이를 입증하기 어렵다. |
| EOI | 사건 순서 보존 개선 | 통제 실험 근거가 있다. 실제 복원 12개 모두 사건 대응률 부족으로 보류됐으며, 관련 순서 지표 대비 차별성과 실제 모델 변화 반영을 확인해야 한다. |

현재 우선 작업은 실제로 개선할 오류를 정하고, 해당 후보의 관측·정답 문제와 모델 변경을 함께 다루는 것이다.
FSO·UEP를 반드시 두 지표로 채택하거나 세 후보를 모두 끝까지 개발할 필요는 없다.
목표 오류와의 연결, 신뢰할 수 있는 측정, 관련 기존 지표 대비 기여를 바탕으로 1~2개를 선정한다.

잔존 지표 `ghost_max`와 FSO 존재 성분의 동일성은 [v5 결과](FSO_UEP_RESULTS.md)의 기존 기여 판단을
따른다. 이름을 바꾼 같은 값을 별개의 신규 지표로 세지 않는다. v5와 v6 평가기 비교는 지표 구현 비교이며,
LGVSC 30-step·10-step 비교 역시 생성 설정 비교다. 둘 모두 새 복원 모델의 우위를 입증한 결과는 아니다.

## 6. 문서 적용 범위와 기존 기록

앞으로의 개발 방향은 [메일 요약](ETRI_FOLLOWUP_EMAIL_SUMMARY.md)을 기준으로
이 문서와 [개발 계획](ETRI_DEVELOPMENT_PLAN.md), [후속 프로토콜](ETRI_FOLLOWUP_PROTOCOL.md)을 따른다.
각 새 실험은 그 목적에 맞는 사전 등록 문서를 별도로 작성한다. 이 지침이 과거 실험의 문턱이나
통과 기준을 소급 변경하지는 않는다.

- 기존 `*_PROTOCOL.md`, `*_RESULTS.md`, 검증 JSON과 `outputs/`의 선언·결과는 해당 실험의
  재현 기록으로 보존한다. 일부 문서는 실행 선언의 해시 검사 대상이다.
