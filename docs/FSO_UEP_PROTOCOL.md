# FSO·EOI·UEP: 사람의 추가 검수 없는 4차 지표 실험

2026-09-15. **점수 계산 전에 자료·수식·관문·채택 기준을 고정하는 문서다.**
[1차 RTE·LSSD](AUTOMATIC_METRIC_PROTOCOL.md), [2차 MTE·OTF](MTE_OTF_PROTOCOL.md),
[3차 ERE·STA](ERE_STA_PROTOCOL.md), [3차 본 평가](ERE_STA_FORMAL_RESULTS.md),
[잔존·지연·STA](EVENT_DURATION_STA_PROTOCOL.md)의 실패 원인 분석을 근거로 만든 후보다.
구현 자체를 연구 성공으로 간주하지 않으며, 성능과 신규성은 실험과 선행 연구 비교로만 판단한다.

## 0. 왜 이 형태인가

여섯 후보 중 통과한 것은 [퇴장 이후 잔존 오류 지속량](EVENT_DURATION_STA_RESULTS.md) 하나다.
[이식 검토](SGDJSCC_METRIC_TRANSFER_REVIEW.md) §2의 세 실패 패턴에 각 후보를 대응시키면
통과 요인은 아이디어가 아니라 **수식의 형태**였다.

| 패턴 | 통과 후보가 가진 성질 | 이번 후보가 그 성질을 유지하는 방법 |
|---|---|---|
| F1 국소 오류 희석 | 분모가 고정 4프레임 창 | 모든 분모를 고정 창(프레임 수)으로 두고 영상 길이·관측 수를 쓰지 않는다 |
| F2 외형 변화 불변성 부재 | "없어야 할 곳에 있음"만 계수 | 금지 상태를 단측으로 정의하고, 운동·방향 상태는 **같은 영상의 사건 전 상태**와 비교하며, 모든 점유량을 **원본에서 측정한 같은 양과 차분**한다 |
| F3 추출기 재현율 상한 | 존재 채널(객체-프레임 재현율 99.25%)만 사용 | 원본 사건을 놓치면 벌점이 아니라 **표본에서 제외**된다. 순서 후보의 미대응 쌍도 분모에서 빠진다 |

지연 후보의 탈락 원인은 사건 일대일 대응 실패가 곧 벌점 1이 되어 정상 480건 중 118건에서
영상 최댓값이 1로 포화된 것이었다. 이번 FSO는 **양성 사건 대응을 요구하지 않는다.**
지연 d초는 `d·fps/H`의 점유량으로 자동 표현되므로 대응 단계 자체가 사라진다.

## 1. 후보 정의

### 1.1 FSO — 금지 상태 점유량

원본 사건 `e`(종류, 시각 `t_e`, 트랙 `τ`)가 참이면 그 전후 `H`프레임 동안 어떤 상태가 금지된다.

```
occ_X(e) = (1/H) · Σ_{t∈W} 1[X에서 금지 상태 관측]
FSO(e)   = max(0, occ_B(e) − occ_A(e))          A=원본, B=복원
영상 점수 = 측정 가능한 사건의 최댓값, 없으면 null
문턱     = 개발 정상군 95백분위(higher), 엄격한 score > threshold
```

| 인스턴스 | 앵커 사건 | 창 `W` | 금지 상태 | 대상 오류 |
|---|---|---|---|---|
| `fso_presence` | `exit` | `[t_e, t_e+H)` | 대응 엔티티의 존재 | 유령 잔존·재등장 |
| `fso_premature` | `enter` | `[t_e−H, t_e)` | 대응 엔티티의 존재 | 등장 시점 선행 |
| `fso_motion` | `stop` | `[t_e, t_e+H)` | 자기 기준 속도 초과 | 정지 미반영 |
| `fso_heading` | `turn` | `[t_e, t_e+H)` | 자기 기준 구 방향 ±45° 유지 | 방향 전환 미반영 |

`fso_max`는 네 인스턴스의 측정 가능한 사건 전체의 최댓값이다. **가중합이 아니다** —
[계획](ETRI_DEVELOPMENT_PLAN.md) §1의 임의 가중합 금지와 SRS 미채택 판정에 따른다.
`H = 4`프레임(0.5초)이며 0.5초와 1초 지속은 모두 1로 포화된다. 장기 잔존 시간의 대체 지표가 아니다.

**자기 기준 상태(핵심).** 운동·방향 상태의 기준은 원본이 아니라 **그 영상 자신의 사건 전
`C=2`프레임 평균 잔여 속도** `h_pre_X`다. 금지 판정의 속도 하한은
`max(0.25, ρ·‖h_pre_X‖)` px/frame이며 방향은 `h_pre_X`와의 각도로 본다.
전역 카메라 이동·회전은 `h_pre`와 `v(t)`에 같이 들어가므로 1차적으로 상쇄된다.
`h_pre`가 양쪽 영상에서 관측되지 않으면 그 질의는 0이 아니라 **측정 불가**다.

**원본 차분.** `occ_A`는 원본 트랙 `τ`와 **같은 영상 안의 형제 조각**(프레임 비중첩,
DINO 프로토타입 cosine ≥0.80, 정규화 위치 거리 ≤0.35)을 합친 엔티티로 계산한다.
[잔존 후보의 오탐 3건이 모두 원본 퇴장 사건의 오탐](EVENT_DURATION_STA_RESULTS.md) §2였고
그 객체는 원본에도 계속 존재했다. 참 사건에서는 `occ_A = 0`이므로 통과한 수치는 바뀌지 않는다.
이 보정이 자연 영상의 가려짐·화면 밖 이동을 해결한다고 주장하지 않는다.

**측정 상태.** `unobservable`(원본 트랙 3프레임 미만, 복원 트랙 부재, 앵커 부재,
운동·방향의 `h_pre` 부재), `right_censored`(창이 클립 경계를 벗어남), `observed`.
결측을 0으로 대치하지 않으며 측정률을 따로 보고한다.

### 1.2 EOI — 사건 순서 역전율

```
대응: 종류 동일 + 엔티티 동일 + 방향 차 ≤1, 비용 |Δt|의 Hungarian, 시간 창 없음
분모: t_A(i)+δ ≤ t_A(j)인 대응된 순서쌍 (δ = 0.375초)
EOI = |{t_B(i') ≥ t_B(j')+δ}| / |분모|,  대응쌍이 없으면 null
```

미대응 사건은 벌점이 아니라 분모 축소다(F3). 시간 창을 두지 않는 이유는 뒤로 이동한 사건도
대응 가능해야 하기 때문이다. Kendall tau·시간 순서 과제와 인접하므로 신규성은
"자동 추출 사건의 대응쌍만을 분모로 쓰고 censoring을 명시" 범위로만 주장한다.

### 1.3 UEP — 근거 없는 존재 점유량

기존 STA 네 성분 중 **GHR만 클래스 재현율 100%·AUC 1.000**이었다. 실패한 것은 최대 성분
판정 규칙과 정상 강건성이었다. GHR을 원인 분류기에서 떼어내 FSO와 같은 형태로 재구성한다.

```
복원 트랙 j에 대해: 원본 대응이 없고(explained=False),
  RX 근거 프레임 = 복호 상태가 ok인 수신 영상에서 j에 대응하는 트랙이 존재하는 프레임
UEP(j) = min(1, |j의 존재 프레임 − RX 근거 프레임| / H)
UEP    = max_j UEP(j),  복원 트랙이 없거나 상태가 없으면 null, 미대응 트랙이 없으면 0
```

기존 지표가 입력조차 갖지 않는 **수신된 표현**을 제3 입력으로 쓴다. 다만
CHAIR·Ragas faithfulness와의 중복을 [신규성 검토](ERE_STA_NOVELTY_REVIEW.md)가 이미 기록했다.
차별점 주장은 "RX 근거 + 고정 창 점유량 + censoring" 범위로 한정한다.

### 1.4 제거 비교(ablation)

각 인스턴스의 원본 차분 없는 값 `*_raw`를 함께 등록한다. `fso_presence_raw`는
기존 통과 지표 `ghost_max`와 같은 양이므로 구현 동등성 검사에 쓴다.

## 2. 자료와 정답

### 2.1 원본

- 새 렌더러 `metric_v5_cases.py`. 3계열 `turn_exit_relay`·`stop_first_relay`·`late_entrance_relay`,
  각 계열 개발 8개(seed 260915300+)·평가 8개(seed 260915600+) = **개발 24개·평가 24개**.
  32프레임, 192×320, 8 Hz의 절차적 그래픽 장면이다.
- 계열마다 네 객체가 각각 `turn`→`exit`(객체 1), `stop`(객체 2), `enter`(객체 3), 정지(객체 4)를
  담당하므로 **네 인스턴스 모두가 모든 원본에서 양성 표본을 받는다.** 계열은 사건 순서와
  기하가 다르다. 방향 전환은 약 180° 반전이다. 고정 추출기가 150° 초과만 전환으로 선언하므로
  91° 전환을 넣으면 실패가 아니라 구조적 측정 불가가 되기 때문이다.
- 1~4차 실험의 원본 RGB SHA256과 교집합이 없음을 `prepare`가 확인하고 거부한다.
- 같은 렌더러의 다른 seed·다른 계열이며 **자연 영상 일반화는 검증하지 않는다.**

### 2.2 정상 대조군

`identity`, `brightness20`, `texture`, `camera`, `palette` — 4차의 고정 대조군과 동일한
구현이다. 외형 불변성을 같은 조건에서 시험하기 위해 바꾸지 않았다.
렌더러 정답 `centers`/`visible`이 원본과 완전히 같아야 채택하며 `prepare`가 검사한다.

### 2.3 오류 개입과 정답 관문

| 개입 | 강도 | 대상 후보 |
|---|---|---|
| `ghost_hold` | 2/4/8프레임 | `fso_presence` |
| `ghost_return` | 2프레임 | `fso_presence` |
| `premature_enter` | 2/4프레임 | `fso_premature` |
| `stop_overrun` | 2/4/8프레임 | `fso_motion` |
| `turn_overrun` | 2/4프레임 | `fso_heading` |
| `order_swap` | 계열별 사건 간격 | `eoi` |
| `unsupported_addition` | 12.5/25% | `uep` |

**정답 기준(사전 고정).** 렌더러 운동학에서 계산한 **대상 인스턴스의 점유량 오라클이
엄격히 증가**해야 오류 사례로 채택한다. 순서 개입은 참 순서쌍이 하나 이상 역전돼야 한다.
`prepare`가 위반 시 실행을 중단한다.

**사건 열 기준과의 차이를 명시한다.** 2프레임(0.25초) 개입은 기존 `truth_event_change`의
±0.25초 대응 허용치 안에 들어가므로 사건 열 기준으로는 "변화 없음"이 된다. 이런 사례 수를
`truth_audit.json`에 따로 집계한다. 사건 열 기준 지표가 구조적으로 볼 수 없는 구간이며,
이 사례를 근거로 그 지표들을 실패라고 주장하지 않는다. 점유량 정답은 렌더러가 독립적으로 기록한다.

### 2.4 STA/UEP 경로

4차와 동일한 고정 `sta_video_validation.simulate`를 쓴다. 32장 PNG 키프레임, 검사합 확인,
직전 정상 프레임 유지 raster 복호기이며 캡션은 쓰지 않는다. 정상군과 송신 누락·패킷 손실·
비트 손상·생성 정지·객체 추가를 12.5/25%로 만든다. UEP의 주 대상은 객체 추가이고,
나머지 네 개입은 **다른 원인에서의 오탐 검사**로 쓴다.
LGVSC 생성 디코더나 실제 무선 채널의 성능 실험이 아니다.

### 2.5 지표 입력

후보에는 RGB 관측과 복호 상태만 넣는다. 렌더러 ID·마스크·사건 시각·개입 이름은
독립 정답 감사에만 쓴다. 검출기 누락을 실제 객체 부재의 정답이라고 주장하지 않는다.

## 3. 사전 관문 (점수 계산 전)

| 관문 | 기준 | 자료 |
|---|---|---|
| 원본 사건 추출 재현율 | ≥0.8 | 새 **개발** 계열 24개 |
| 원본 사건 추출 정밀도 | ≥0.8 | 동일 |
| 앵커 종류별 재현율(`enter`/`exit`/`stop`/`turn`) | 각 ≥0.8 | 동일 |
| 정답 점유량 증가 | 전 사례 | 평가 원본의 렌더러 정답(무결성·적격성 검사만) |

관문 미달이면 문턱을 동결하지 않고 `development`가 중단된다. 관문 재감사는 개발 자료에서만
하며, 평가 원본 RGB는 `calibration.json`이 존재하기 전에는 관측하지 않는다.

### 3.1 사전 점수 개정 기록 (2026-09-15)

평가 원본 점수 **0건** 상태에서 개발 자료만 보고 확정한 두 항목이다.

1. **구현 동등성 확인.** 4차 사례 312건에서 `fso_presence_raw`가 통과 지표 `ghost_max`와
   최대 차이 **0.0**으로 일치함을 확인했다. 새 구현이 통과한 양을 그대로 포함한다는 근거다.
2. **자기 기준 속도 비율 `ρ` 선정.** 절대 하한만(ρ=0) 쓰면 4차 정상 대조군에서
   `fso_motion` 평균 0.071·문턱 0.5가 되어 짧은 오류가 묻혔다. 개발 자료에서 ρ를
   0/0.3/0.5/0.7로 비교한 결과는 다음과 같다.

   | ρ | 정상 평균 | 문턱 | 정상 오탐 | `event_delay` 검출 | `never_update` 검출 |
   |---:|---:|---:|---:|---:|---:|
   | 0.0 | 0.071 | 0.5 | 4.3% | 33.3% | 50.0% |
   | 0.3 | 0.016 | 0.0 | 2.8% | 50.0% | 50.0% |
   | **0.5** | **0.012** | **0.0** | **2.0%** | **50.0%** | **50.0%** |
   | 0.7 | 0.009 | 0.0 | 1.7% | 50.0% | 50.0% |

   0.3~0.7이 사실상 같은 평탄 구간이므로 중앙값 **ρ = 0.5**를 선정했다. 극단값을 고르지
   않았고, 이 표의 4차 개입은 계열에 따라 앵커 종류가 달라 정지 대상만의 민감도가 아니다.
   근거는 `outputs/fso_development_probe/residual_speed_ratio.json`에 보존한다.

이 개정 이후 `PARAMETERS`·창 길이·문턱 규칙·채택 기준은 바꾸지 않는다.

## 4. 문턱과 비교

- **문턱은 후보와 기준선이 같은 정상군을 공유한다**: 기존 3차 렌더 정상 480건 + 4차 정상
  120건 = **600건(원본 72개)**. 이 자료는 [4차 결과](EVENT_DURATION_STA_RESULTS.md) §8에 따라
  전부 개발 자료다. 4차가 같은 480건에서 문턱을 정한 전례를 따른다.
- 새 개발 계열 120건의 대조군으로 계산한 대안 문턱도 `calibration.json`에 기록하되
  **사용하지 않는다**(선언된 진단). 계열 분포 차이를 독자가 볼 수 있게 하기 위한 것이다.
- 사전 등록 비교 기준선: `ghost_max`(통과한 기존 지표), `delay_max`, `sfr_inferred`,
  `ere`, `ser`, `tlp_alex`, `mte_tail`, `idf1_mask_error`, `lpips_alex`, `tof_farneback`.
  같은 RGB·같은 시점·같은 정상군 문턱에서 계산한다.
- 기존 실행의 시각 비교량은 고정 `VisualObserver.compare`를 관측값만으로 그대로 옮긴
  `compare_observations`로 계산하며, 실제 쌍 하나에서 두 경로의 일치를 `development`가 검사한다.

## 5. 채택 기준

- 오류 종류마다 **AUC ≥0.9, 검출률 ≥0.8, 정상 오탐률 ≤0.1, 측정률 ≥0.95**(양성·정상 모두).
- 대상 사건 측정률 ≥0.8, 독립 오라클과의 점유량 MAE ≤0.25.
- 우위 주장은 **모든 사전 등록 기준선**에 대해 원본 단위 대응 AUC 차이의 95% 구간
  하한이 0보다 클 때만 허용한다. 특히 `ghost_max` 대비 우위가 없으면 `fso_presence`는
  기존 지표의 재구성으로만 보고한다.
- 결측은 0으로 대치하지 않고 검출률에서 미검출로 센다.
- 통계: 평가 원본 24개를 단위로 bootstrap 1,000회(seed 20260915), 95% 구간. 사례를 독립
  원본처럼 세지 않는다. 계열별 결과도 별도 보고한다.
- 관문 통과와 신규성은 별개다. 기존 기술 조합이 주 구성이면 실용 진단 도구로만 보고한다.
- 평가 결과를 본 뒤 수식·문턱·대상 대응을 바꾸지 않는다. 바꾸면 새 원본·새 seed가 필요하다.

## 6. 선행 연구와 겹치는 부분

| 연구 | 이미 있는 요소 | 이번 후보가 입증해야 할 부분 |
|---|---|---|
| 4차 잔존 점유량(본 저장소) | 퇴장 후 존재 점유량 | `fso_presence`는 같은 양의 재구성이다. 신규성은 나머지 세 인스턴스와 원본 차분에 한정 |
| [HOTA](https://arxiv.org/abs/2009.07736), [IDF1](https://arxiv.org/abs/1609.01775) | 검출·연결 분리, 전역 대응 | 존재 채널을 쓰는 사실만으로 신규성이 되지 않음 |
| [TecoGAN tOF·tLP](https://github.com/thunil/TecoGAN/blob/master/metrics.py) | 광류·지각 시간 차이 | 재렌더링 정상군에서의 오탐 차이 |
| ActivityNet TAL 공식 평가 | 사건 단위 시간 대응 채점 | FSO는 양성 대응을 요구하지 않는 점의 실익 |
| Kendall tau / 시간 순서 과제 | 순서 비교 | EOI의 분모 축소·censoring 구성 |
| [CHAIR](https://aclanthology.org/D18-1437/), Ragas faithfulness | 근거 없는 생성 단위의 비율 | UEP의 시간 점유량·RX 근거 구성 |
| Kaplan–Meier 생존 분석 | censoring 처리 | 이 후보들은 생존함수가 아니다. 고정 창 점유량이라고 명시한다 |

## 7. 한계

- 절차적 합성 3계열·48개 원본의 pilot 규모다. 자연 영상·실제 LGVSC 복원의 유효성은 미검증이다.
- `fso_motion`·`fso_heading`은 RAFT 잔여 광류에 의존하므로 카메라 보정 실패에 노출된다.
  자기 기준 정의가 1차 상쇄를 제공하지만 완전한 불변성을 보장하지 않는다.
- 원본 차분은 원본 추출 오탐 중 형제 조각으로 설명되는 것만 제거한다.
- UEP의 정상군은 TX=RX=원본이며 최종 복원만 외형이 바뀐다. 일반적인 생성 복원의
  오탐률을 대변하지 않는다.
- SAM2·DINOv2·RAFT는 정답이 아니라 측정 도구다. 도구 오차를 §3의 관문에서 따로 측정한다.
- 개발 자료를 반복 사용하므로 과적합 위험이 남는다. 평가 원본 점수는 개정 시점에 0건이었다.

## 8. 재현

```bash
metric_run=outputs/fso_uep_20260915_v1
bash scripts/run_metric_v5.sh prepare     "$metric_run"
bash scripts/run_metric_v5.sh declare     "$metric_run"
bash scripts/run_metric_v5.sh development "$metric_run"   # 관문 + 문턱 동결
bash scripts/run_metric_v5.sh visual      "$metric_run"
bash scripts/run_metric_v5.sh pixel       "$metric_run"
bash scripts/run_metric_v5.sh report      "$metric_run"
```

`prepare`가 코드·이전 실험 protocol·원본·픽셀 해시와 이 문서를 고정한다.
`development`는 `calibration.json`이 없을 때만 실행되고, `visual`/`pixel`은 동결된
`calibration.json`의 해시를 요구한다. 같은 seed의 재실행은 반복 검증이지 새 독립 시험이 아니다.
시각 단계는 `.local/metric_v2_env`(Torch 2.12.0+cu130), 픽셀 단계는 `lgvsc`(Torch 2.2.2+cu121)를
쓰고 시스템 드라이버를 바꾸지 않는다. 결과는 [결과 문서](FSO_UEP_RESULTS.md)에 기록한다.
